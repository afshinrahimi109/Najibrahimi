# 🐠 دیانا (Diana) — ماهیِ زنده‌ی هوشمند، ارتش ۱۴۰ ایجنت و کارخانهٔ راه‌اندازی کسب‌وکار

**دیانا** یک سیستم چندعامله‌ی (Multi-Agent) زنده است با همان معماری **ارکستراتور–کارگر** سیستم تحقیقاتی کلود (Anthropic):
مغز رهبر (خودِ دیانا 👑) هدف شما را تجزیه می‌کند، برنامه را در حافظه ذخیره می‌کند، متخصص‌های مناسب را **موازی** به کار می‌اندازد،
**ارزیاب کیفیت** به هر خروجی نمره می‌دهد (و خروجی ضعیف را دوباره اجرا می‌کند) و در پایان دیانا نتیجه نهایی را ترکیب، با صدا اعلام و در گاوصندوق ذخیره می‌کند.

و همه‌ی این‌ها در قالب یک **ماهی طلایی سه‌بعدی زنده و سخنگو** که در آکواریومش شنا می‌کند، غذا می‌خورد، با شما حرف می‌زند و به فعالیت هر دپارتمان ایجنت‌ها واکنش نشان می‌دهد! 🫧

> 🌌 **سیستم پنج‌بُعدی دیانا:** سه بُعدِ فضا (آکواریوم و ماهی سه‌بعدی) + بُعدِ زمان (حافظه‌ی ماندگار روی هاست) + بُعدِ احساس (شخصیت، حالت روحی و واکنش زنده‌ی ماهی)

## 🚀 اجرا (بدون نصب هیچ‌چیز!)

دیانا فقط با **کتابخانه‌ی استاندارد پایتون** ساخته شده — `pip install` لازم نیست.

```bash
cd diana
python3 server.py
```

بعد در مرورگر باز کنید: **http://localhost:8000**

| محیط | دستور |
|---|---|
| لینوکس / مک | `./run.sh` یا `python3 server.py` |
| ویندوز | دابل‌کلیک روی `start.bat` |
| 📱 ترموکس (اندروید) | `pkg install python git` ← `git clone <آدرس مخزن>` ← `cd Najibrahimi/diana` ← `python server.py` و بعد در مرورگر موبایل: `http://localhost:8000` |
| داکر | `docker build -t diana . && docker run -p 8000:8000 -v diana-data:/app/data diana` |

## ☁️ هاست رایگان (دیانا همیشه آنلاین)

به جای اجاره‌ی سرور پولی، از پلن‌های رایگان استفاده کنید — فایل آماده در پروژه هست:

| سرویس | روش |
|---|---|
| **Render.com** (پیشنهادی) | مخزن گیت‌هاب را ایمپورت کنید؛ فایل `render.yaml` همه‌چیز را خودکار انجام می‌دهد |
| **Railway / Fly.io** | با `Dockerfile` موجود دیپلو کنید |
| **PythonAnywhere** | کد را آپلود و `server.py` را به‌عنوان وب‌اپ اجرا کنید |
| **موبایل/کامپیوتر خودتان** | `python3 online.py` ← تونل رایگان ngrok/Cloudflare/Tailscale + وصل مجدد خودکار (راهنما: [STATIC-IP.md](STATIC-IP.md)) |

> 🌐 **آدرس ثابت رایگان میخواهی؟** [STATIC-IP.md](STATIC-IP.md) را بخوان. خلاصه: `python3 online.py --setup` و سپس `python3 online.py` —
> یک آدرس `https://....ngrok-free.dev` دائمی، رمز عبور خودکار و وصل مجدد بعد از قطعی اینترنت.
>
> 💾 روی هاست‌های ابری برای ماندگاری دائمی حافظه، یک دیسک دائمی (Persistent Disk) به پوشه‌ی `data/` وصل کنید.

## 🧠 زنجیره‌ی مغز رایگان (بدون پرداخت به هیچ سایتی)

هرجا سرویسی پولی بود، معادل رایگانش ساخته شده است. دیانا به‌ترتیب این‌ها را امتحان می‌کند:

1. **کلید رایگان خودتان** (اختیاری): Groq ← Gemini ← OpenRouter — از صفحه‌ی «تنظیمات» وارد کنید
2. **Pollinations رایگان** — بدون کلید و بدون ثبت‌نام (از سمت سرور و همچنین از سمت مرورگر شما)
3. **مغز آفلاین داخلی فارسی** — تشخیص نیت، حافظه و ابزارهای واقعی حتی بدون اینترنت

| نیاز | راه‌حل پولی معمول | راه‌حل رایگان دیانا ✅ |

| مدل زبانی (LLM) | اشتراک ماهانه API | Pollinations بدون کلید + پلن رایگان Groq/Gemini |

| صدا (TTS/STT) | ElevenLabs و... | Web Speech API رایگان مرورگر |
| جستجوی وب | Tavily/SerpAPI | DuckDuckGo + Wikipedia API رایگان |
| دیتابیس | دیتابیس ابری پولی | ذخیره‌سازی JSON اتمیک دست‌ساز روی هاست شما |
| میزبانی | VPS | پلن رایگان Render/Railway یا موبایل خودتان |

### 🔑 گرفتن کلید رایگان (اختیاری — برای مغز قوی‌تر)

## 🚀 کارخانهٔ راه‌اندازی کسب‌وکار (Business Launch Factory)

این همان چیزی است که می‌گویی «یک ایجنت شرکت راه اندازی کرد، تحقیق کرد، فروشنده و مشتری پیدا کرد،
قرارداد بست و خودش پشت صحنه کار را اجرا می‌کند». در دیانا این کار یک موتور اختصاصی است:

**۷ مرحلهٔ اجرایی با خروجی واقعی و قابل دانلود**

| # | مرحله | خروجی |
|---|---|---|
| ۱ | 🔍 تحقیق و اعتبارسنجی بازار | پروفایل مشتری ایده‌آل، نقشهٔ رقبا، آزمون ۷۲ ساعتهٔ تقاضا |
| ۲ | 🎁 پیشنهاد و قیمت‌گذاری | پیشنهاد یک‌خطی، سه بستهٔ قیمتی، سیاست تخفیف، مرزهای کار |
| ۳ | 🏭 فروشنده و تأمین‌کننده | لیست تأمین‌کنندگان، قالب RFQ، معیار انتخاب، نقشهٔ جایگزین |
| ۴ | 🎯 پیدا کردن مشتری | ۵ کانال، اسکریپت پیام اول، سیستم پیگیری ۳ مرحله‌ای، ریاضیات سرنخ روزانه |
| ۵ | 🤝 مذاکره و قرارداد | ساختار ۱۵ بندی قرارداد، BATNA، مسیر امضا و پیش‌پرداخت |
| ۶ | ⚙️ اجرای پشت صحنه | پروژهٔ ۵ مرحله‌ای هر سفارش، چک‌لیست کیفیت، SLA پشتیبانی |
| ۷ | 📣 برند و رشد | هویت یک‌صفحه‌ای، تقویم محتوای هفتگی، برنامهٔ اثبات اجتماعی |

📖 **راهنمای کامل این بخش:** [LAUNCH.md](LAUNCH.md) — فرم‌ها، API، فایل‌های خروجی، ۱۲ قاعدهٔ اتوماسیون و نسخهٔ وب.

**به‌علاوهٔ:**

- **💰 حساب‌وکتاب قیف فروش:** درآمد هدف، سرنخ لازم، جلسهٔ لازم، بودجهٔ جذب، سود و بررسی ظرفیت اجرا — همه با عدد.
- **⚙️ ۱۲ قاعدهٔ اتوماسیون پشت صحنه:** سرنخ → امتیازدهی → پیام اول → پیگیری → پیشنهاد → RFQ تأمین‌کننده →
  قرارداد → فاکتور و پیش‌پرداخت → پروژهٔ اجرا → کنترل کیفیت → رضایت‌سنجی → گزارش هفتگی؛ با نقشهٔ اتصال به
  Gmail، Google Calendar، Google Docs/Drive، Dropbox Sign، Linear و Supabase.
- **📦 بستهٔ کامل:** یک فایل «گزارش مادر»، ۷ سند مرحله‌ای و یک نقشهٔ اتوماسیون، همه در گاوصندوق دیانا.
- **زنده و قابل تماشا:** صفحهٔ **«🚀 اتاق جنگ کسب‌وکار»** مراحل را با وضعیت، متخصص مسئول، امتیاز ارزیاب
  و پیش‌نمایش خروجی نشان می‌دهد.

**چطور استفاده کنم؟**

۱. از نوار بالا **🚀 اتاق جنگ کسب‌وکار** را باز کن، یا در چت بنویس:

```
یه شرکت راه‌اندازی کن که هم تحقیق کنه، هم فروشنده پیدا کنه، هم مشتری پیدا کنه،
هم قرارداد ببندد و هم خودش پشت صحنه کار اجرا رو بچرخونه — کارم: طراحی سایت برای کافه‌ها در اصفهان
```

۲. در فرم، ایده، شهر، مبلغ هر قرارداد، هدف مشتری در ماه و ظرفیت اجرا را بگذار (یا دکمهٔ «🧠 از متن آزاد پر کن»).
۳. «🚀 شروع راه‌اندازی» را بزن و مراحل را زنده ببین. در پایان، گزارش و نقشهٔ اتوماسیون را از گاوصندوق دانلود کن.

**نکتهٔ صداقت:** دیانا واقعاً برنامه، اسکریپت، قالب قرارداد، استعلام قیمت و متن‌ها را می‌سازد و
با مغز ابری رایگان تحلیل زنده هم اضافه می‌کند؛ ولی **ارسال پیام، امضا و پرداخت** را باید خودت یا از طریق
اتصال همان سرویس‌ها (Gmail/Dropbox/Linear/Supabase) تأیید کنی. هیچ چیزی بی‌اجازه از طرف تو ارسال نمی‌شود.

## 🔗 اتصال و لینک (اگر صفحه بالا نیامد یا اتصال قطع شد)

دیانا سه لایهٔ اتصال دارد تا در هر محیطی زنده بماند:

| لایه | مسیر | کار |
|---|---|---|
| ۱. سلامت | `GET /api/ping` و `/healthz` | تست سبک اتصال، نسخه، پورت‌ها و زمان سرور (بدون رمز) |
| ۲. جریان زنده — اول | `ws://HOST/stream?after=N` (WebSocket، **همان پورت**) | سریع‌ترین مسیر؛ از همان درِ HTTP رد می‌شود پس پروکسی پیش‌نمایش آن را می‌پذیرد |
| ۲ب. WebSocket پورت دوم | `ws://HOST:WS_PORT/stream?after=N` | اگر پروکسی ارتقای هم‌مبدأ را نپذیرفت |
| ۳. جریان زنده — دوم | `GET /api/events` (SSE) | اگر WebSocket در دسترس نبود (یا پورت دوم آزاد نبود) |
| ۴. جایگزین خودکار | `GET /api/events/poll?after=N&wait=18` | اگر مرورگر/proxy هر دو کانال push را بست |

زنجیره خودکار است: **WebSocket → SSE → Polling**؛ هر ۶۰ ثانیه یک‌بار تلاش می‌کند به WebSocket ارتقا پیدا کند.
مرورگر **اول همان‌مبدأ** (`wss://همان‌میزبان/stream`) را امتحان می‌کند — این مسیر به پورت دومی نیاز ندارد —
و اگر جواب نداد پورت دوم (`DIANA_WS_PORT`، پیش‌فرض `PORT+1`) را. اگر پکیج `websockets` نصب نباشد
دیانا بدون خطا فقط SSE/Polling می‌دهد (`pip install -r requirements.txt`).

**در پنل پیش‌نمایش Arena لازم نیست پورت دومی باز باشد**؛ فقط پورت اصلی کافی است. اگر هیچ‌کدام از دو مسیر
WebSocket باز نشد، نشانگر خودش روی `🟢 (SSE)` یا `🟡 Polling` می‌ماند و هیچ رویدادی گم نمی‌شود.

**در رابط کاربری:** نشانگر بالای صفحه (`🟢 اتصال زنده (WebSocket)` / `🟢 (SSE)` / `🟡 Polling` / `🔴 قطع`) با یک کلیک
اتصال را دوباره می‌سازد؛ تأخیر (`⚡ ms`) و نسخه هم کنارش نشان داده می‌شود.
در **⚙️ تنظیمات** بخش «🔗 وضعیت اتصال دیانا» پنج چیز را تست می‌کند: سرور، وضعیت و مغز،
جریان زنده، گاوصندوق/حافظه و مغز ابری — به‌همراه **لینک فعلی دیانا** و دکمهٔ کپی.

**اگر لینک پیش‌نمایش عوض شد:** در پنل Arena لینک تازهٔ پیش‌نمایش را باز کن؛ همهٔ داده‌ها
(`diana/data/`) روی همان سرور می‌مانند. برای لینک **ثابت همیشگی**:

```bash
cd diana
python3 online.py --setup     # انتخاب ngrok / Cloudflare / Render + رمز
python3 online.py             # آدرس ثابت + وصل مجدد خودکار
```

جزئیات: [STATIC-IP.md](STATIC-IP.md) | روی هاست رایگان: `render.yaml` یا `Dockerfile`.

> 🩺 **سریع‌ترین تشخیص:** اگر صفحه سفید یا «قطع» است، اول `python3 server.py` را ببین که در حال
> اجراست و پورت درست (`PORT`) را گوش می‌دهد؛ بعد در مرورگر `/api/ping` را باز کن. اگر جواب
> `{"ok": true, "diana": true, ...}` آمد، سرور سالم است و مشکل فقط لینک/پروکسی است.

- **🚀 اتاق جنگ کسب‌وکار** — فرم راه‌اندازی، حساب‌وکتاب قیف فروش، ۷ مرحلهٔ زنده، شبکهٔ اتوماسیون و تاریخچه
- **👥 ارتش ایجنت‌ها** — جستجو و مأموریت مستقیم به هر یک از ۱۴۰ متخصص
- **📋 مأموریت‌ها** — تاریخچه‌ی کامل مأموریت‌ها و گزارش‌ها
- **🗄️ گاوصندوق و حافظه** — فایل‌های ساخته‌شده، خاطرات دیانا از شما، یادآوری‌ها
- **⚙️ تنظیمات** — اسم شما، صدا، مغز ابری و کلیدهای رایگان

یه برنامه بنویس که اعداد اول تا ۱۰۰ رو پیدا کنه
حساب کن ۴۵ ضربدر ۱۲ به علاوه ۷ و میانگین اعداد ۱۰ و ۲۰ و ۳۰ رو بگو
یه عکس از قلعه‌ای روی کوه در غروب بساز
برنامه سفر سه‌روزه به شیراز بچین

این متن رو خلاصه کن: «...»

## 🏗️ معماری فنی

```
diana/
├── server.py       # سرور HTTP + رویدادهای زنده SSE (فقط stdlib) + Basic Auth اختیاری
├── online.py       # 🌐 آدرس ثابت رایگان: تونل + وصل مجدد خودکار + رمز تصادفی
├── brain.py        # 🧠 مغز ارکستراتور: تجزیه ← اجرای موازی ← ارزیاب ← ترکیب نهایی
├── agents.py       # رجیستری ارتش ۱۴۰ ایجنت + مسیریاب هوشمند فارسی (IDF)
├── launch.py       # 🚀 کارخانهٔ راه‌اندازی کسب‌وکار: ۷ مرحله، حساب‌وکتاب، ۱۲ قاعدهٔ اتوماسیون
├── tools.py        # ابزارهای واقعی: اجرای کد، وب، فایل، ریاضی، متن، تصویر
├── llm.py          # زنجیره مغز ابری رایگان (Groq/Gemini/OpenRouter/Pollinations)
├── local_brain.py  # مغز آفلاین فارسی: تشخیص نیت و گفتگو
├── memory.py       # حافظه بلندمدت ماندگار (JSON اتمیک)
├── static/         # رابط کاربری: آکواریوم Three.js + صفحات
└── data/           # حافظه، تنظیمات و گاوصندوق فایل‌ها (روی هاست شما)
```
