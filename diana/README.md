# 🐠 دیانا (Diana) — ماهیِ زنده‌ی هوشمند و ارتش ۱۲۰ ایجنت متخصص

**دیانا** یک سیستم چندعامله‌ی (Multi-Agent) زنده است با همان معماری **ارکستراتور–کارگر** سیستم تحقیقاتی کلود (Anthropic):
مغز رهبر (خودِ دیانا 👑) هدف شما را تجزیه می‌کند، برنامه را در حافظه ذخیره می‌کند، متخصص‌های مناسب را **موازی** به کار می‌اندازد،
**ارزیاب کیفیت** به هر خروجی نمره می‌دهد (و خروجی ضعیف را دوباره اجرا می‌کند) و در پایان دیانا نتیجه نهایی را ترکیب، با صدا اعلام و در گاوصندوق ذخیره می‌کند.

و همه‌ی این‌ها در قالب یک **ماهی طلایی سه‌بعدی زنده و سخنگو** که در آکواریومش شنا می‌کند، غذا می‌خورد، با شما حرف می‌زند و به فعالیت هر دپارتمان ایجنت‌ها واکنش نشان می‌دهد! 🫧

> 🌌 **سیستم پنج‌بُعدی دیانا:** سه بُعدِ فضا (آکواریوم و ماهی سه‌بعدی) + بُعدِ زمان (حافظه‌ی ماندگار روی هاست) + بُعدِ احساس (شخصیت، حالت روحی و واکنش زنده‌ی ماهی)

## 🚀 اجرا (بدون نصب هیچ‌چیز!)

دیانا فقط با **کتابخانه‌ی استاندارد پایتون** ساخته شده — `pip install` لازم نیست.

```bash
cd diana
python3 server.py
```

بعد در مرورگر باز کنید: **http://localhost:8000**

| محیط | دستور |
|---|---|
| لینوکس / مک | `./run.sh` یا `python3 server.py` |
| ویندوز | دابل‌کلیک روی `start.bat` |
| 📱 ترموکس (اندروید) | `pkg install python git` ← `git clone <آدرس مخزن>` ← `cd Najibrahimi/diana` ← `python server.py` و بعد در مرورگر موبایل: `http://localhost:8000` |
| داکر | `docker build -t diana . && docker run -p 8000:8000 -v diana-data:/app/data diana` |

## ☁️ هاست رایگان (دیانا همیشه آنلاین)

به جای اجاره‌ی سرور پولی، از پلن‌های رایگان استفاده کنید — فایل آماده در پروژه هست:

| سرویس | روش |
|---|---|
| **Render.com** (پیشنهادی) | مخزن گیت‌هاب را ایمپورت کنید؛ فایل `render.yaml` همه‌چیز را خودکار انجام می‌دهد |
| **Railway / Fly.io** | با `Dockerfile` موجود دیپلو کنید |
| **PythonAnywhere** | کد را آپلود و `server.py` را به‌عنوان وب‌اپ اجرا کنید |
| **موبایل/کامپیوتر خودتان** | از ترموکس یا کامپیوتر خانگی + تونل رایگان Cloudflare برای دسترسی اینترنتی |

> 💾 روی هاست‌های ابری برای ماندگاری دائمی حافظه، یک دیسک دائمی (Persistent Disk) به پوشه‌ی `data/` وصل کنید.

## 🧠 زنجیره‌ی مغز رایگان (بدون پرداخت به هیچ سایتی)

هرجا سرویسی پولی بود، معادل رایگانش ساخته شده است. دیانا به‌ترتیب این‌ها را امتحان می‌کند:

1. **کلید رایگان خودتان** (اختیاری): Groq ← Gemini ← OpenRouter — از صفحه‌ی «تنظیمات» وارد کنید
2. **Pollinations رایگان** — بدون کلید و بدون ثبت‌نام (از سمت سرور و همچنین از سمت مرورگر شما)
3. **مغز آفلاین داخلی فارسی** — تشخیص نیت، حافظه و ابزارهای واقعی حتی بدون اینترنت

| نیاز | راه‌حل پولی معمول | راه‌حل رایگان دیانا ✅ |
|---|---|---|
| مدل زبانی (LLM) | اشتراک ماهانه API | Pollinations بدون کلید + پلن رایگان Groq/Gemini |
| ساخت عکس | Midjourney/DALL·E | `image.pollinations.ai` رایگان |
| صدا (TTS/STT) | ElevenLabs و... | Web Speech API رایگان مرورگر |
| جستجوی وب | Tavily/SerpAPI | DuckDuckGo + Wikipedia API رایگان |
| دیتابیس | دیتابیس ابری پولی | ذخیره‌سازی JSON اتمیک دست‌ساز روی هاست شما |
| میزبانی | VPS | پلن رایگان Render/Railway یا موبایل خودتان |

### 🔑 گرفتن کلید رایگان (اختیاری — برای مغز قوی‌تر)
- **Groq** (سریع‌ترین): [console.groq.com](https://console.groq.com) ← ساخت API Key رایگان
- **Gemini**: [aistudio.google.com](https://aistudio.google.com) ← Get API Key
- **OpenRouter**: [openrouter.ai](https://openrouter.ai) ← مدل‌های با برچسب `free`

## 🖥️ صفحات سیستم

- **🏠 آکواریوم** — دیانای سه‌بعدی زنده + چت صوتی/متنی (صفحه‌ی اصلی تعامل)
- **🧠 مرکز فرماندهی** — تماشای زنده‌ی مغز ارکستراتور: تجزیه، اجرای موازی، نمره‌ی ارزیاب، گزارش نهایی
- **👥 ارتش ایجنت‌ها** — جستجو و مأموریت مستقیم به هر یک از ۱۲۰ متخصص
- **📋 مأموریت‌ها** — تاریخچه‌ی کامل مأموریت‌ها و گزارش‌ها
- **🗄️ گاوصندوق و حافظه** — فایل‌های ساخته‌شده، خاطرات دیانا از شما، یادآوری‌ها
- **⚙️ تنظیمات** — اسم شما، صدا، مغز ابری و کلیدهای رایگان

## 🏗️ معماری فنی

```
diana/
├── server.py       # سرور HTTP + رویدادهای زنده SSE (فقط stdlib)
├── brain.py        # 🧠 مغز ارکستراتور: تجزیه ← اجرای موازی ← ارزیاب ← ترکیب نهایی
├── agents.py       # رجیستری ارتش ۱۲۰ ایجنت + مسیریاب هوشمند فارسی (IDF)
├── tools.py        # ابزارهای واقعی: اجرای کد، وب، فایل، ریاضی، متن، تصویر
├── llm.py          # زنجیره مغز ابری رایگان (Groq/Gemini/OpenRouter/Pollinations)
├── local_brain.py  # مغز آفلاین فارسی: تشخیص نیت و گفتگو
├── memory.py       # حافظه بلندمدت ماندگار (JSON اتمیک)
├── static/         # رابط کاربری: آکواریوم Three.js + صفحات
└── data/           # حافظه، تنظیمات و گاوصندوق فایل‌ها (روی هاست شما)
```
