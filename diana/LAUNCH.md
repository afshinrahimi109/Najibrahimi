# 🚀 دپارتمان راه‌اندازی کسب‌وکار — کارخانهٔ «شرکت‌سازی» دیانا

این بخش همان خواستهٔ اصلی است:

> «یک ایجنت شرکت راه‌اندازی می‌کند: تحقیق می‌کند، فروشنده (تأمین‌کننده) پیدا می‌کند،
> مشتری پیدا می‌کند، قرارداد می‌بندد و خودش پشت صحنه اجرای کار را می‌چرخاند.»

دیانا این کار را با یک **موتور اختصاصی ۷ مرحله‌ای** انجام می‌دهد، نه با یک پاسخ متنی.

---

## ۱) چطور راه بیندازم؟

**راه اول — اتاق جنگ (پیشنهادی):** نوار بالا ← **🚀 اتاق جنگ کسب‌وکار** ← فرم را پر کن ← «🚀 شروع راه‌اندازی».

**راه دوم — از چت:** هر جمله‌ای شبیه این بنویس:

```
یه شرکت راه‌اندازی کن که هم تحقیق کنه، هم فروشنده پیدا کنه، هم مشتری پیدا کنه،
هم قرارداد ببندد و هم خودش پشت صحنه اجرا رو بچرخونه — کارم: طراحی سایت برای کافه‌ها در اصفهان
```

دیانا نیت را تشخیص می‌دهد (`kind = launch`)، فرم را از متن پر می‌کند و موتور را روشن می‌کند.

**راه سوم — API:**

```bash
curl -X POST localhost:8000/api/launch -H 'Content-Type: application/json' \
  -d '{"idea":"طراحی سایت برای کافه‌ها","city":"اصفهان","ticket":8,"customers":15}'
```

## ۲) هفت مرحله و خروجی هر کدام

| # | مرحله | متخصص مسئول | خروجی واقعی |
|---|---|---|---|
| ۱ | 🔍 تحقیق و اعتبارسنجی بازار | 🔎 تحلیل‌گر بازار هدف | پروفایل مشتری ایده‌آل، نقشهٔ ۳ رقیب، آزمون ۷۲ ساعتهٔ تقاضا |
| ۲ | 🎁 پیشنهاد و قیمت | 🎁 طراح پیشنهاد ارزش | پیشنهاد یک‌خطی، سه بستهٔ قیمتی، سقف تخفیف، مرزهای کار |
| ۳ | 🏭 تأمین‌کننده | 🧭 کارشناس سورسینگ | لیست تأمین‌کننده، قالب RFQ، معیار انتخاب ۴۰/۳۰/۲۰/۱۰، نقشهٔ جایگزین |
| ۴ | 🎯 پیدا کردن مشتری | 🎯 شکارچی سرنخ | ۵ کانال، اسکریپت پیام اول و سه پیام دوم، پیگیری ۳ مرحله‌ای، سرنخ روزانه |
| ۵ | 🤝 قرارداد | 📜 تنظیم‌کننده قرارداد تجاری | قرارداد ۱۵ بندی + BATNA + مسیر امضا و پیش‌پرداخت |
| ۶ | ⚙️ اجرای پشت صحنه | ⚙️ مدیر اجرای سفارش | پروژهٔ ۵ مرحله‌ای هر سفارش، چک‌لیست کیفیت، SLA پشتیبانی |
| ۷ | 📣 برند و رشد | 📣 استراتژیست برند | وعدهٔ برند، تقویم محتوای هفتگی، برنامهٔ اثبات اجتماعی |

هر مرحله یک **سند فارسی آمادهٔ استفاده** می‌سازد و در گاوصندوق ذخیره می‌شود.
اگر مغز ابری رایگان در دسترس باشد، یک «تحلیل زندهٔ متخصص» هم به همان سند اضافه می‌شود.

## ۵) چه فایل‌هایی می‌گیری؟

در گاوصندوق (صفحهٔ 🗄️) و در کارت‌های «📄 اسناد آمادهٔ استفاده»:

- `launch-<id>-00-plan.md` — سند مادر: اعداد، ۷ مرحله، تقویم ۹۰ روزه
- `launch-<id>-01…07-*.md` — هفت سند اجرایی مرحله‌ای
- `launch-<id>-contract-draft.md` — پیش‌نویس قرارداد ۱۵ بندی
- `launch-<id>-rfq-template.md` — قالب درخواست قیمت
- `launch-<id>-automation.md` — نقشهٔ ۱۲ قاعدهٔ اتوماسیون
- `launch-<id>-runbook.md` — بستهٔ کامل (همه‌چیز یک‌جا)

## ۶) API

| متد | مسیر | کار |
|---|---|---|
| GET | `/api/launch` | فهرست کسب‌وکارها + ۷ مرحله + پیش‌فرض‌ها |
| POST | `/api/launch` | شروع راه‌اندازی (`{idea, city, ticket, customers, ...}`) |
| POST | `/api/launch/quote` | فقط محاسبهٔ اعداد + برنامهٔ مادر (بدون اجرا) |
| POST | `/api/launch/parse` | استخراج فیلدها از متن آزاد |
| GET | `/api/launch/<id>` | جزئیات یک راه‌اندازی (خروجی مراحل کوتاه‌شده) |
| GET | `/api/launch/<id>/full` | همان، با خروجی کامل |
| POST | `/api/message` | با متن «شرکت راه‌اندازی کن…» → `kind: "launch"` |

رویدادهای زندهٔ SSE: `launch_created`، `launch_stage_started`، `launch_stage_done`،
`launch_progress`، `launch_ready`، `launch_failed`، `diana_say`.

## ۷) نسخهٔ وب (GitHub Pages)

`docs/` همین قابلیت را بدون سرور پایتون دارد:

- `docs/launch-data.js` — خودکار از `launch.py` تولید می‌شود (مراحل، کتاب راهنما، قواعد، متخصص‌ها)
- `docs/launch-web.js` — همان موتور در جاوااسکریپت (۷ مرحله، اعداد، اسناد، اتوماسیون) + رهگیری `fetch`
  تا رابط کاربری بدون تغییر کار کند؛ حافظه و گاوصندوق در `localStorage`

برای بازتولید داده‌های وب پس از تغییر `launch.py`:

```bash
cd diana && python3 - <<'PY'
import sys, json; sys.path.insert(0, '.')
import launch, agents
data = {
  "stages": [{k: s[k] for k in ("id","step","icon","owner","deliverable","why")} for s in launch.STAGES],
  "playbook": launch.PLAYBOOK, "domainNames": launch.DOMAIN_NAMES, "stop": sorted(launch.STOP),
  "defaults": launch.DEFAULTS,
  "automation": [{k: a[k] for k in ("id","trigger","title","action","systems")}
                 for a in launch.automation_specs(launch.normalize_fields({}))],
  "agents": [a for a in agents.AGENTS if a["dept"] == "launch"],
}
js = "// تولیدشده خودکار از launch.py\nwindow.DIANA_LAUNCH_DATA = " + json.dumps(data, ensure_ascii=True, separators=(",", ":")) + ";\n"
for p in ("static/launch-data.js", "../docs/launch-data.js"):
    open(p, "w", encoding="utf-8").write(js)
PY
```

فایل‌های `app.js`، `style.css` و `index.html` بین `diana/static` و `docs/` یکی هستند
(فقط مسیرهای دارایی و اسکریپت‌های وب تفاوت دارند).

## ۸) صداقت مهندسی

- دیانا **واقعاً** برنامه، اسکریپت، قالب قرارداد، RFQ، پیام و محاسبات را می‌سازد.
- برای هر مرحله می‌تواند با مغز ابری رایگان (Groq/Gemini/OpenRouter/Pollinations) تحلیل زنده اضافه کند؛
  اگر اینترنت یا مغز نبود، کتاب راهنمای اجرایی داخلی (کامل و قابل استفاده) جای آن را می‌گیرد.
- دیانا **به‌جای تو پیام نمی‌فرستد، امضا نمی‌کند و پول جابه‌جا نمی‌کند.** این کارها با اتصال
  Gmail/Dropbox/Linear/Supabase و تأیید خودت انجام می‌شود.
- پیش‌نویس قرارداد، مشاورهٔ حقوقی نیست؛ پیش از قرارداد بزرگ حتماً بازبینی حقوقی بگیر.
