# 🎬 تیزر تبلیغاتی «کی‌کرفت کره»

ویدیوی عمودی **1080×1920** (مناسب استوری اینستاگرام، ریلز، تیک‌تاک، شورتس و تلگرام) با **نریشن فارسی** و **متن فارسی متحرک**.

| فایل | توضیح |
| --- | --- |
| `k-craft-korea-teaser-web.mp4` | نسخه سبک و بهینه (۱۵ مگابایت، H.264 + AAC) — همین را به اشتراک بگذارید |
| `k-craft-korea-teaser.mp4` | نسخه مستر با کیفیت بالاتر (۴۰ مگابایت، CRF 20) — با `build_video.py` بازتولید می‌شود و در گیت نگه داشته نمی‌شود |
| `poster.jpg` | تصویر کاور / تامبنیل |
| `assets/*.png` | ۶ صحنه وُکسل تولید‌شده اختصاصی برای ویدیو |
| `audio/n1..n4.mp3` | نریشن فارسی، چهار بخش |
| `fonts/` | فونت Vazirmatn (FD) با مجوز OFL برای متن فارسی |

## بازتولید

```bash
pip install pillow imageio-ffmpeg arabic-reshaper python-bidi
python3 build_video.py
```

اسکریپت، تصاویر ثابت را با حرکت دوربین (Ken Burns) و پارالاکس حرکت می‌دهد،
گلبرگ‌های وُکسل، اسکن‌لاین، وینیت و سایه‌های خوانایی اضافه می‌کند،
متن فارسی را با `arabic-reshaper` + `python-bidi` شکل می‌دهد و نریشن را روی آن می‌نشاند.

### تغییر متن یا صحنه
- متن‌ها و زمان‌بندی: لیست `SCENES` در `build_video.py`
- کارت پایانی: تابع `end_card_frame`
- نریشن: فایل‌های `audio/n*.mp3` را جایگزین کنید (مدت ویدیو خودکار با نریشن هم‌تراز می‌شود)
