# 📸 ایجنت اینستاگرام

یک برنامهٔ **تک‌فایل** پایتون برای ادارهٔ پیج اینستاگرام از روی گوشی یا کامپیوتر، با پنل فارسی. دو جور کار می‌کند:

- **بدون اتصال (انتشار با خودت):** ایده‌ات را در یک جمله می‌نویسی؛ ایجنت کپشن و هشتگ می‌نویسد، با هوش مصنوعی تصویر می‌گیرد،
  عکس نهایی یا **ویدیوی کوتاه با صدای گویندهٔ فارسی** را روی همان دستگاه می‌سازد و سر وقت یادآوری می‌کند. انتشار را خودت در اپ اینستاگرام انجام می‌دهی.
  نه توکن می‌خواهد و نه سایت Meta؛ برای جاهایی مثل ایران که «Meta for Developers» باز نمی‌شود همین راه است.
- **با اتصال (توکن رسمی Meta):** علاوه بر این‌ها خودش منتشر و زمان‌بندی می‌کند، کامنت‌ها و دایرکت‌ها را در یک صندوق نشان می‌دهد،
  طبق قانون‌هایی که می‌نویسی جواب می‌دهد و آمار پیج را نشان می‌دهد.

- هیچ کتابخانه‌ای نصب نمی‌خواهد (فقط پایتون ۳٫۸ به بالا).
- پنل فارسی و راست‌به‌چپ دارد که در مرورگر گوشی باز می‌شود.
- **هیچ‌وقت رمز پیج را نمی‌خواهد** و سراغ راه‌های غیررسمی نمی‌رود؛ اتصال فقط با API رسمی اینستاگرام (Meta) است.
- همه‌چیز (توکن، پیش‌نویس‌ها، تنظیمات) فقط روی دستگاه خودت می‌ماند.

```bash
python insta_agent.py --demo     # اول این را بزن: یک پیج ساختگی، بدون توکن و بدون اینترنت
python insta_agent.py            # اجرای واقعی
```

## چه کارهایی می‌کند؟

| بخش | کار |
| --- | --- |
| **ساختن محتوا («بساز»)** | از روی یک ایده: کپشن و هشتگ، تیتر روی تصویر، تصویر با هوش مصنوعی، و عکس نهایی (۱۰۸۰×۱۳۵۰) یا ریل چندصحنه‌ای (MP4، ۱۰۸۰×۱۹۲۰) که روی خود دستگاه ساخته می‌شود. |
| **صدای ویدیو** | متن هر صحنه نوشته می‌شود و یک **گویندهٔ فارسیِ رایگان** آن را روی خود گوشی می‌خواند (یک بار دانلود، بعد بدون کلید و بدون اینترنت)؛ یا صدای خودت را ضبط می‌کنی؛ یا با کلید Pollinations از گوینده‌های آن سرویس. صدا داخل همان فایل MP4 می‌نشیند. |
| **انتشار با خودت** | بدون اتصال پیج: فایل را با یک دکمه به اپ اینستاگرام می‌دهد (یا در گوشی ذخیره می‌کند)، کپشن را کپی می‌کند، یادآوری می‌گذارد و اگر تلگرام وصل باشد سر وقت فایل و کپشن را همان‌جا می‌فرستد. |
| **انتشار** | پست تکی، پست چندتایی (۲ تا ۲۰ تایی)، ریل و استوری — همین حالا یا در زمان دلخواه. کپشن، متن جایگزین عکس، «اولین کامنت»، بستن کامنت‌ها، نمایش ریل در صفحهٔ اصلی. |
| **زمان‌بندی** | صف انتشار، پیش‌نویس‌ها، پیشنهاد «بهترین ساعت» از روی پست‌های قبلی خودت. اگر اینترنت قطع شود خودش دوباره تلاش می‌کند و **هیچ پستی را دو بار منتشر نمی‌کند**. |
| **کامنت‌ها** | همهٔ کامنت‌های بی‌پاسخ در یک صندوق: پاسخ، پیام خصوصی به نویسندهٔ کامنت، مخفی‌کردن، حذف، «رسیدگی شد». |
| **دایرکت** | دیدن گفتگوها و جواب دادن (در پنجرهٔ ۲۴ ساعتهٔ اینستاگرام). |
| **پاسخ خودکار** | قانون با کلمهٔ کلیدی (مثلاً «قیمت» ← متن آماده + پیام خصوصی)، چند متن تصادفی، `{username}`، مخفی‌کردن خودکار کامنت‌های تبلیغاتی. |
| **آمار** | ریچ، بازدید، تعامل، رشد دنبال‌کننده، بهترین پست‌ها، بهترین ساعت‌ها، سن و جنسیت و شهر مخاطبان، آمار هر پست. |
| **دستیار** | کپشن و هشتگ پیشنهادی، ایدهٔ پست، چیدن برنامهٔ محتوایی به شکل پیش‌نویس، پیشنهاد پاسخ برای کامنت و دایرکت. |
| **خبر دادن** | هشدار و گزارش شبانه در تلگرام (اختیاری). |

ردیف‌های «انتشار» تا «آمار» به اتصال پیج نیاز دارند. همهٔ کارهای خودکار **در شروع خاموش‌اند**؛ هر کدام را خودت در بخش «ایجنت» روشن می‌کنی.

## شروع سریع

### روی گوشی اندروید (Termux) — فقط یک خط

همین یک خط را در Termux بچسبان و Enter بزن:

```bash
termux-wake-lock; pkg install -y python cloudflared && curl -fsSLO https://github.com/afshinrahimi109/Najibrahimi/raw/main/insta-agent/insta_agent.py && python insta_agent.py
```

این خط گوشی را بیدار نگه می‌دارد، پایتون و `cloudflared` (برای انتشار از گالری) را نصب می‌کند، برنامه را که فقط یک فایل است می‌گیرد و اجرایش می‌کند.

برنامه یک نشانی مثل `http://127.0.0.1:8787/?k=ABCDE-FGHJK` چاپ می‌کند و مرورگر را باز می‌کند.
اگر باز نشد همان نشانی را در کروم گوشی بزن. از منوی کروم «Add to Home screen» را بزنی، پنل مثل یک اپ روی صفحهٔ گوشی می‌نشیند.

- **دفعه‌های بعد:** `termux-wake-lock; python insta_agent.py`
- **به‌روزرسانی:** همان خط بالا را دوباره بزن. داده‌ها و اتصال پیج در `~/.insta_agent` می‌مانند.
- **فقط می‌خواهی ببینی چه شکلی است؟** آخر خط بنویس `--demo` (پیج ساختگی، بدون توکن).
- اگر کل مخزن را می‌خواهی: `pkg install -y git && git clone https://github.com/afshinrahimi109/Najibrahimi && cd Najibrahimi/insta-agent`

### روی کامپیوتر (ویندوز، لینوکس، مک)

```bash
git clone https://github.com/afshinrahimi109/Najibrahimi
cd Najibrahimi/insta-agent
python insta_agent.py
```

برنامه فقط همین یک فایل `insta_agent.py` است؛ اگر بخواهی می‌توانی فقط همان را برداری و اجرا کنی
(روی لینوکس و مک: `curl -fsSLO https://github.com/afshinrahimi109/Najibrahimi/raw/main/insta-agent/insta_agent.py && python3 insta_agent.py`).

### گزینه‌های اجرا

| دستور | کار |
| --- | --- |
| `python insta_agent.py --demo` | حالت نمایشی با پیج ساختگی `@demo.cafe` (هیچ چیزی به اینستاگرام واقعی نمی‌رود) |
| `python insta_agent.py --show-key` | نمایش دوبارهٔ کد ورود پنل |

| `python insta_agent.py --host 0.0.0.0` | باز شدن پنل از دستگاه‌های دیگرِ همان وای‌فای (کد ورود لازم است) |
| `python insta_agent.py --no-browser` | مرورگر را خودکار باز نکن |
| `python insta_agent.py --data پوشه` | جای نگهداری داده‌ها (پیش‌فرض `~/.insta_agent`) |

## ساختن عکس و ریل از روی یک ایده

در خانه (یا با دکمهٔ «بساز» در پست جدید) ایده‌ات را بنویس، مثلاً «تخفیف ۲۰٪ لاتهٔ پاییزی تا آخر هفته»، و «عکس بساز» یا «ویدیو بساز» را بزن.

1. **متن:** دستیار کپشن، ۳ تا ۵ هشتگ، یک تیتر کوتاه برای روی تصویر و (برای ریل) نوشتهٔ هر صحنه و جمله‌ای که گوینده روی آن صحنه می‌خواند را می‌نویسد و برای تصویرساز توصیف انگلیسی می‌دهد.
2. **تصویر:** ایجنت از سرویس‌های هوش مصنوعی تصویر می‌گیرد؛ برای ریل، هر صحنه یک تصویر.
3. **صدا (فقط ریل):** گوینده متن هر صحنه را می‌خواند و هر صحنه به اندازهٔ صدای خودش طول می‌کشد.
4. **ساخت:** عکس نهایی (تصویر + نوشتهٔ فارسی با فونت وزیرمتن) یا ریل (تصویرها با حرکت آرام، محوشدن، نوشتهٔ هر صحنه و صدای گوینده) روی خود دستگاه ساخته می‌شود.
   می‌توانی نوشته‌ها و متن گوینده را عوض کنی، با صدا پیش‌نمایش بگیری، چیدمان دیگری برداری یا برای هر صحنه تصویر تازه بخواهی.
5. نتیجه با کپشن به «پست جدید» می‌رود: با اتصال پیج منتشر یا زمان‌بندی می‌شود؛ بدون اتصال، خودت پستش می‌کنی (پایین را ببین).

### صدای ویدیو: سه راه

| راه | چه می‌خواهد | چطور است |
| --- | --- | --- |
| **گویندهٔ فارسی روی خود دستگاه** (پیش‌فرض) | یک بار دانلود، حدود ۸۵ مگابایت (۹۳ مگابایت جا روی دستگاه) | صدای مردانهٔ «امیر». رایگان، بدون کلید و بدون ثبت‌نام؛ بعد از دانلود اینترنت نمی‌خواهد و متن از گوشی بیرون نمی‌رود. |
| **صدای خودت** | میکروفون گوشی | متن صحنه‌ها را نشان می‌دهد، تو می‌خوانی؛ صحنه‌ها با طول صدای تو هماهنگ می‌شوند. |
| **گوینده‌های Pollinations** | کلید Pollinations (اعتبار رایگان اولیه دارد) | شش صدا (زن و مرد). این صداها برای انگلیسی ساخته شده‌اند و فارسی‌شان را خودت باید بشنوی و داوری کنی. |

**گویندهٔ روی دستگاه چطور کار می‌کند؟** دکمهٔ «دانلود گویندهٔ فارسی» (در خانه، در «بساز» یا در تنظیمات) شش فایل را می‌گیرد:
صدای فارسی «امیر» از مجموعهٔ [Piper](https://huggingface.co/rhasspy/piper-voices)، واج‌نویس Piper (espeak-ng) و [ONNX Runtime Web](https://www.npmjs.com/package/onnxruntime-web).
ایجنت هر فایل را با اثر انگشت (SHA-256) نسخهٔ اصلی می‌سنجد و فایلِ ناجور را کنار می‌گذارد. اگر ارتباط وسط کار قطع شود، دفعهٔ بعد از همان‌جا ادامه می‌دهد؛
اگر یک سرور جواب ندهد سراغ سرور بعدی می‌رود (npm، jsDelivr، unpkg، cdnjs، Hugging Face و دو رونوشت روی GitHub).
از آن به بعد، مرورگر همین فایل‌ها را در یک «worker» اجرا می‌کند که فقط اجازهٔ حرف زدن با خود ایجنت را دارد.

روراست دربارهٔ کیفیتش:

- صدا **ماشینی ولی فارسی و قابل‌فهم** است. فارسی زیر و زبر نمی‌نویسد، پس گاهی کسرهٔ اضافه را نمی‌خواند («کافهٔ کوچک ما» به‌جای «کافهٔ کوچکِ ما») یا واژه‌ای را اشتباه تلفظ می‌کند.
  چاره: متن گویندهٔ آن صحنه را عوض کن، یا کسره را خودت بگذار («کوچکِ»)؛ با «پخش با صدا» دوباره بشنو.
- عددها، درصد و ساعت پیش از خواندن به حروف برمی‌گردند («۲۰٪» ← «بیست درصد»، «۸:۳۰» ← «هشت و سی»).
- روی کامپیوتر آزمایشی، هر ثانیه صدا حدود یک‌سوم ثانیه کار می‌برد؛ روی گوشی کندتر است (چند ثانیه برای هر صحنه) و حدود ۳۰۰ مگابایت حافظهٔ آزاد می‌خواهد.
- اینستاگرام صدای AAC می‌خواهد. Chrome روی اندروید، ویندوز و مک AAC می‌سازد؛ اگر مرورگری فقط Opus بلد باشد (مثل Chrome روی لینوکس)، پنل همان را می‌گذارد و هشدار می‌دهد.

**سرویس‌ها و انتظار درست از آن‌ها**

| | بدون ثبت‌نام (پیش‌فرض) | با کلید Pollinations |
| --- | --- | --- |
| متن | یک مدل کوچک رایگان: هر ۴۵ ثانیه یک پاسخ، ۲۰ تا ۴۰ ثانیه برای هر پست، فارسیِ گاهی ناشیانه (قابل ویرایش) | مدل بهتر، بدون انتظار |
| تصویر | Pollinations رایگان (هر ۴۵ ثانیه یک تصویر، حدود ۷۰۰×۸۵۰، با نشان کوچک خودش در گوشه) و AI Horde (شبکهٔ داوطلبانه: ۵۱۲×۶۴۰، گاهی با صف) به نوبت | بزرگ‌تر، بدون انتظار و بدون نشان |
| صدا | گویندهٔ فارسی روی خود دستگاه (یک بار دانلود) یا صدای خودت؛ سرویس رایگانِ بدون کلید، صدا نمی‌دهد | شش گویندهٔ دیگر |

- کلید را از <https://enter.pollinations.ai> می‌گیری و در «تنظیمات ← ساخت عکس و ویدیو» می‌گذاری. سرویس تصویر دلخواه (سازگار با OpenAI) هم همان‌جا قابل تنظیم است.
- اگر هیچ سرویسی جواب ندهد، ایجنت **طرح خودش** را می‌کشد (زمینهٔ رنگی + نوشته) تا کار نخوابد. اگر دستیار متن در دسترس نباشد، برای ایدهٔ فارسی تصویر هوش مصنوعی ساخته نمی‌شود، چون تصویرسازها فارسی را نمی‌فهمند و تصویر بی‌ربط می‌دهند.
- **ریل** از چند تصویر با حرکت، نوشته و صدای گوینده ساخته می‌شود؛ آهنگ زمینه را موقع انتشار در اینستاگرام اضافه کن. فیلمی که خودِ هوش مصنوعی فریم‌به‌فریم بسازد (آدم و صحنهٔ متحرک) فقط در سرویس‌های پولی هست و در این ایجنت نیست.
- ریل با انکودر H.264 خود مرورگر ساخته می‌شود؛ **Chrome** پیشنهاد می‌شود. تا پایان ساخت، همان صفحه را باز نگه دار.

## بدون اتصال: انتشار با خودت

در صفحهٔ اول «بدون اتصال شروع کن» را بزن. از آن به بعد:

- هر پستی که آماده است یک کارت «انتشار با خودت» دارد: **ارسال به اینستاگرام** (فایل مستقیم به اپ می‌رود و کپشن کپی می‌شود؛ آنجا بچسبانش)، **ذخیره** (در پوشهٔ Download گوشی) و **کپی کپشن**. بعد از انتشار «منتشر کردم» را بزن تا در فهرست ثبت شود.
- برای هر پست می‌توانی **یادآوری** بگذاری؛ سر وقت در پنل خبر می‌دهد. اگر تلگرام را وصل کرده باشی (تنظیمات ← اعلان در تلگرام)، همان موقع **فایل و کپشن** هم به گفتگوی خودت با ربات فرستاده می‌شود و از همان‌جا به اینستاگرام می‌دهی‌اش.
- کامنت‌ها، دایرکت و آمار را در خود اپ اینستاگرام می‌بینی؛ ایجنت بدون توکن به آن‌ها دسترسی ندارد.
- هر وقت توکن Meta داشتی، از «ایجنت ← اتصال با توکن متا» وصل می‌شوی و همان پیش‌نویس‌ها را می‌تواند خودش منتشر کند.

## وصل‌کردن پیج (فقط یک بار، حدود ۵ دقیقه)

ایجنت با یک **توکن** به پیج وصل می‌شود. توکن را خود Meta به تو می‌دهد و هر وقت بخواهی می‌توانی باطلش کنی.

> اگر سایت Meta نوشت «Meta for Developers در این مکان در دسترس نیست» (مثلاً در ایران)، این راه بسته است و دور زدنش را پیشنهاد نمی‌کنیم؛ از «بدون اتصال» استفاده کن.

1. پیج باید **حرفه‌ای** (Business یا Creator) و **عمومی** (نه خصوصی) باشد: اینستاگرام ← تنظیمات ← نوع حساب ← «تغییر به حساب حرفه‌ای». رایگان است.
2. در <https://developers.facebook.com/apps/> وارد شو و **Create App** را بزن.
   اگر «Use case» پرسید، گزینهٔ مربوط به اینستاگرام (*Manage messaging & content on Instagram*) را بردار؛ در فرم قدیمی‌تر: *Other* ← *Business*.
3. در برنامه‌ای که ساختی محصول **Instagram** را اضافه کن و به بخش **API setup with Instagram login** برو.
4. در قسمت **Generate access tokens** پیج خودت را اضافه کن (Add account)، با همان پیج وارد شو، همهٔ دسترسی‌ها را تأیید کن و **Generate token** را بزن.
5. رشتهٔ بلندی که با `IGAA` شروع می‌شود را کپی کن و در پنل بچسبان.

- توکن ۶۰ روز اعتبار دارد؛ ایجنت هر هفته خودش تمدیدش می‌کند. اگر برنامه بیش از ۶۰ روز خاموش بماند باید توکن تازه بسازی.
- توکن‌های قدیمی‌تر «Facebook Login» (که با `EAA` شروع می‌شوند) هم پذیرفته می‌شوند؛ ایجنت خودش صفحهٔ فیسبوکِ وصل به پیج را پیدا می‌کند.
- نام منوها در سایت Meta گاهی عوض می‌شود؛ مقصد همیشه همان بخش «Generate access tokens» زیر محصول Instagram است.
- اینستاگرام بدون فیلترشکن باز نمی‌شود؟ در صفحهٔ اتصال (یا تنظیمات ← پروکسی) نشانی پروکسی **HTTP** فیلترشکن را بده؛ در v2rayNG معمولاً `http://127.0.0.1:10809`.

## انتشار از گالری و «لینک عمومی»

اینستاگرام فایل را از تو نمی‌گیرد؛ خودش آن را از یک **نشانی اینترنتی** برمی‌دارد. پس وقتی عکسی را از گالری انتخاب می‌کنی،
ایجنت باید چند دقیقه یک لینک عمومی برای همان فایل بسازد. سه راه دارد (تنظیمات ← انتشار از گالری):

1. **تونل `cloudflared` (پیشنهادی، رایگان، بدون ثبت‌نام):** کافی است نصب باشد (`pkg install cloudflared`). ایجنت فقط وقتی لازم است تونل را باز می‌کند و فقط همان فایل‌های در حال انتشار از آن دیده می‌شوند، نه پنل.
2. **میزبان موقت:** فایل برای یک ساعت روی سرویس عمومی `litterbox.catbox.moe` گذاشته می‌شود. چیزی نصب نمی‌خواهد ولی فایل از دستگاهت بیرون می‌رود؛ برای همین باید خودت روشنش کنی.
3. **نشانی عمومی خودت:** اگر ایجنت روی سرور یا پشت دامنهٔ خودت است.

اگر به‌جای فایل، **لینک مستقیم** عکس یا ویدیو (`https://…`) بدهی، هیچ‌کدام لازم نیست.

عکس‌ها در مرورگر خودکار به JPEG تبدیل و اگر لازم باشد به نسبت مجاز اینستاگرام (۴:۵ تا ۱٫۹۱:۱) بریده می‌شوند.
ویدیو باید MP4 یا MOV باشد (بهتر است H.264 و عمودی ۹:۱۶)؛ ایجنت ویدیو را تبدیل نمی‌کند.

## پاسخ خودکار و ترمزهای ایمنی

در بخش «ایجنت» قانون می‌سازی: «اگر کامنت شامل *قیمت* یا *چنده* بود ← این متن را زیرش بنویس و این پیام را خصوصی بفرست».
حروف «ي/ی» و «ك/ک»، نیم‌فاصله و بزرگی و کوچکی حروف فرقی نمی‌کند.

برای این‌که پیج شبیه ربات نشود و اینستاگرام حساس نشود، ایجنت این ترمزها را دارد:

- فقط به چیزهایی جواب می‌دهد که **بعد از روشن‌کردن کلید** رسیده‌اند و کمتر از ۲۴ ساعت از آن‌ها گذشته است؛ کامنت‌های قدیمی را یک‌جا جواب نمی‌دهد.
- به هر کامنت یا پیام **حداکثر یک بار** جواب می‌دهد، حتی اگر وسط کار اینترنت قطع شود.
- به هر نفر هر ۳۰ دقیقه یک پاسخ خودکار (قابل تغییر).
- سقف ۳۰ کار خودکار در ساعت (قابل تغییر).
- «ساعت سکوت»: در این بازه (مثلاً ۲۳ تا ۸) چیزی فرستاده نمی‌شود و صبح جواب داده می‌شود.
- کلید «ایجنت روشن/خاموش» در خانه همه‌چیز را یک‌جا نگه می‌دارد.
- پاسخ‌های هوش مصنوعی به‌طور پیش‌فرض فقط **پیشنهاد** هستند و در کادر پاسخ می‌نشینند؛ فرستادن خودکارشان کلید جدا دارد.

## تنظیم با فایل `.env` (اختیاری)

همه‌چیز از داخل پنل تنظیم می‌شود. اگر بخواهی، می‌توانی فایل [`.env.example`](.env.example) را به نام `.env` کنار برنامه کپی کنی:

| متغیر | کار |
| --- | --- |
| `AGENT_PORT` / `AGENT_HOST` | پورت و نشانی پنل (پیش‌فرض `8787` و `127.0.0.1`) |
| `AGENT_PASSWORD` | کد ورود دلخواه به‌جای کد خودکار |
| `AGENT_DATA_DIR` | پوشهٔ داده‌ها |
| `AGENT_PROXY` | پروکسی HTTP برای رسیدن به اینستاگرام، تلگرام و سرویس‌های هوش مصنوعی |
| `AGENT_PUBLIC_URL` | نشانی عمومی خودت برای فایل‌ها |
| `AGENT_TUNNEL_CMD` | دستور تونل دلخواه؛ `{port}` با پورت فایل‌ها جایگزین می‌شود |
| `IG_ACCESS_TOKEN` | توکن (به‌جای چسباندن در پنل) |
| `IG_API_VERSION` | نسخهٔ API (پیش‌فرض `v26.0`؛ اگر پذیرفته نشود خودش نسخه‌های دیگر را امتحان می‌کند) |
| `AGENT_AI_URL` | نشانی یک سرویس سازگار با OpenAI برای دستیار |
| `AGENT_IMAGE_URL` / `AGENT_GEN_URL` / `AGENT_HORDE_URL` | نشانی سرویس‌های تصویر (پیش‌فرض: Pollinations رایگان، Pollinations با کلید، AI Horde) |
| `AGENT_VOICE_MIRROR` | نشانی یک رونوشت از شش فایل گویندهٔ فارسی (با همان نام‌ها)؛ پیش از سرورهای اصلی امتحان می‌شود. فایل‌ها را دستی هم می‌شود در پوشهٔ `voice` کنار داده‌ها گذاشت؛ ایجنت پیش از استفاده می‌سنجدشان. |

## همیشه روشن (Termux)

زمان‌بندی و پاسخ خودکار فقط تا وقتی کار می‌کند که برنامه باز باشد.

- `termux-wake-lock` را بزن و در تنظیمات اندروید «بهینه‌سازی باتری» را برای Termux خاموش کن.
- برای شروع خودکار بعد از روشن شدن گوشی، اپ **Termux:Boot** را نصب کن و:

```bash
mkdir -p ~/.termux/boot
curl -fsSL https://github.com/afshinrahimi109/Najibrahimi/raw/main/insta-agent/termux-boot.sh -o ~/.termux/boot/insta-agent.sh
chmod +x ~/.termux/boot/insta-agent.sh
```

اگر برنامه خاموش بوده، پست‌هایی که کمتر از ۶ ساعت از وقتشان گذشته همان موقعِ روشن شدن منتشر می‌شوند؛ قدیمی‌ترها «جامانده» علامت می‌خورند تا خودت تصمیم بگیری.

## امنیت

- پنل فقط روی خود دستگاه باز می‌شود مگر این‌که خودت `--host 0.0.0.0` بدهی.
- ورود با کدی است که هنگام اجرا در ترمینال چاپ می‌شود؛ بعد از ۸ بار اشتباه، ورود ۱۰ دقیقه بسته می‌شود.
- توکن هیچ‌وقت به مرورگر برنمی‌گردد و در گزارش‌ها هم نوشته نمی‌شود. با «قطع اتصال» از روی دستگاه پاک می‌شود.
- تونل `cloudflared` فقط فایل‌های در حال انتشار را نشان می‌دهد؛ پنل و داده‌ها پشت آن نیستند.
- پوشهٔ داده‌ها (`~/.insta_agent`) را با کسی شریک نشو؛ توکن پیج داخل آن است.
- در «بساز»، **ایده و توصیف تصویر** برای نوشتن و کشیدن به سرویس‌های بیرونی (Pollinations و AI Horde) فرستاده می‌شود؛ چیزی محرمانه در ایده ننویس. کلیدهایی که می‌دهی فقط روی دستگاه می‌مانند و به مرورگر برنمی‌گردند.

## چه چیزهایی شدنی نیست؟ (روراست)

Meta برای این کارها **راه رسمی نگذاشته** و این ایجنت هم سراغ راه‌های غیررسمی (که پیج را در خطر بسته‌شدن می‌گذارند) نمی‌رود:

- فالو/آنفالو، دیدن فهرست دنبال‌کننده‌ها، دیدن استوری دیگران
- ویرایش کپشن یا بیو
- استیکر، لینک، موسیقی و نظرسنجی روی استوری؛ موسیقی کتابخانهٔ اینستاگرام روی ریل
- شروع گفتگو با کسی که خودش پیام نداده، یا جواب بعد از ۲۴ ساعت

دو نکتهٔ دیگر:

- **دایرکت با عموم مردم** فقط وقتی کار می‌کند که برنامه‌ات در Meta «Advanced Access» گرفته باشد (App Review). تا آن موقع فقط با حساب‌هایی که در برنامه نقش دارند کار می‌کند. کامنت‌ها، انتشار و آمار این محدودیت را ندارند.
- اینستاگرام برای انتشار از راه API سقف ۲۴ ساعته دارد؛ ایجنت عدد واقعی را از خود اینستاگرام می‌پرسد و در خانه نشان می‌دهد. سقف خودِ ایجنت ۲۵ پست در روز است که قابل تغییر است.
- ایجنت هیچ پستی را از پیج **حذف نمی‌کند** و چیزی را **لایک نمی‌کند** (Meta برای این دو مجوز جداگانه می‌خواهد)؛ این کارها را از خود اپ اینستاگرام انجام بده.
- **هشتگ:** اینستاگرام از دسامبر ۲۰۲۵ حداکثر ۵ هشتگ را توصیه می‌کند، ولی مرجع API هنوز تا ۳۰ هشتگ را مجاز می‌داند. ایجنت سخت نمی‌گیرد: بالای ۵ هشتگ فقط هشدار می‌دهد و پست را می‌فرستد؛ فقط بالای ۳۰ را نمی‌فرستد. پیشنهادهای خود دستیار از ۵ تا بیشتر نمی‌شود. اگر اینستاگرام پستی را به‌خاطر هشتگ نپذیرد یا کپشن را نگذارد، ایجنت همان را به تو خبر می‌دهد.
- ویدیوی ریل: ۳ ثانیه تا ۱۵ دقیقه و حداکثر ۳۰۰ مگابایت. ویدیوی استوری: حداکثر ۶۰ ثانیه و ۱۰۰ مگابایت. عکس: JPEG تا ۸ مگابایت (پنل خودش تبدیل می‌کند).

## برای توسعه‌دهنده‌ها

داخل همین فایل یک **شبیه‌ساز API اینستاگرام** هست؛ حالت نمایشی و همهٔ تست‌ها با آن کار می‌کنند و اینترنت نمی‌خواهند.

```bash
cd tests
python -m unittest discover -p "test_*.py"     # حدود ۲۹۰ تست: انتشار، صندوق، خودکارها، توکن، آمار، امنیت پنل، «بساز»، گوینده، انتشار دستی

cd ui                                          # پنل در مرورگر واقعی (Node لازم است)
sh setup.sh
python serve.py flows.mjs demo                 # کارهای روزمره: انتشار، زمان‌بندی، پاسخ، قانون، تنظیمات…
python serve.py connect.mjs sim                # ورود با کد، اتصال پیج، قطع اتصال
python serve.py byhand.mjs hand                # بدون اتصال: «بساز» عکس و ریل (بی‌صدا، با صدای خودت، با گوینده) می‌سازد؛ اشتراک، ذخیره، کپی
python check_made.py                           # ریل‌های ساخته‌شده را با ffmpeg از اول تا آخر باز می‌کند و صدایشان را می‌سنجد (pip install imageio-ffmpeg)

python serve.py realvoice.mjs real             # گویندهٔ فارسیِ واقعی: فایل‌ها را دانلود می‌کند (۸۵ مگابایت) و یک ریل با صدا می‌سازد
python check_made.py --real && python listen.py   # ffmpeg ریل را باز می‌کند؛ Whisper می‌نویسد چه شنیده (pip install faster-whisper)
```

در تست‌های معمول به‌جای فایل‌های گوینده چند فایل کوچکِ جانشین از شبیه‌ساز می‌آید (همان نام‌ها، همان مسیر دانلود و سنجش، بوق به‌جای صدا).
مرورگرهای آزمایشی انکودر AAC ندارند؛ برای همین یک تست، AAC ساختهٔ ffmpeg را از نویسندهٔ MP4 خود پنل رد می‌کند و ffmpeg نتیجه را باز می‌کند.

سرویس‌های متن و تصویر هم شبیه‌ساز دارند؛ تست‌های بالا به اینترنت نمی‌روند. برای سنجیدن خودِ سرویس‌های واقعی یک بررسی جدا هست
(`tests/live_check.py`) که فقط وقتی اجرا می‌شود که پیام کامیت `[live-check]` داشته باشد: همان کد «بساز» را از روی سرورهای GitHub
با Pollinations و AI Horde واقعی اجرا می‌کند و نتیجه را (با پیش‌نمایش کوچک تصویرها) در خلاصهٔ اجرا می‌نویسد.
همان‌جا گویندهٔ فارسی هم واقعی سنجیده می‌شود: همهٔ نشانی‌های دانلود یکی‌یکی (هر فایل باید همان نسخهٔ اصلی باشد)، ساخت یک ریل با صدا در کروم واقعی،
و یک تشخیص‌دهندهٔ گفتار که می‌نویسد از صدای گوینده چه فهمیده است؛ خودِ ریل هم به‌صورت «artifact» نگه داشته می‌شود تا بشود گوشش داد.

این تست‌ها روی هر تغییر در GitHub Actions هم اجرا می‌شوند: لینوکس با پایتون ۳٫۸ تا ۳٫۱۵ (۳٫۱۴ همان نسخه‌ای است که Termux روی گوشی نصب می‌کند)، ویندوز، و کروم واقعی.

یادآوری: این تست‌ها رفتار برنامه را در برابر شبیه‌ساز می‌سنجند. شبیه‌ساز از روی مستندات رسمی Meta نوشته شده،
ولی جای اینستاگرام واقعی را نمی‌گیرد؛ اولین پست واقعی را خودت با یک عکس آزمایشی امتحان کن.

درخواست‌هایی که ایجنت می‌فرستد در نوامبر ۲۰۲۶ با این صفحه‌های رسمی Meta تطبیق داده شده است:
[Content Publishing](https://developers.facebook.com/docs/instagram-platform/content-publishing/)،
[IG User Media](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media)،
[Conversations API](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/conversations-api)،
[Changelog](https://developers.facebook.com/docs/instagram-platform/changelog) و
