# 📸 ایجنت اینستاگرام

یک برنامهٔ **تک‌فایل** پایتون که پیج اینستاگرام تو را از روی گوشی یا کامپیوتر مدیریت می‌کند:
پست و ریل و استوری را منتشر یا زمان‌بندی می‌کند، کامنت‌ها و دایرکت‌ها را در یک صندوق نشان می‌دهد،
طبق قانون‌هایی که خودت می‌نویسی جواب می‌دهد و آمار پیج را به فارسی نشانت می‌دهد.

- هیچ کتابخانه‌ای نصب نمی‌خواهد (فقط پایتون ۳٫۸ به بالا).
- پنل فارسی و راست‌به‌چپ دارد که در مرورگر گوشی باز می‌شود.
- **فقط از API رسمی اینستاگرام (Meta)** استفاده می‌کند و **هیچ‌وقت رمز پیج را نمی‌خواهد**؛ برای همین پیج به‌خاطر این ایجنت بسته یا محدود نمی‌شود.
- همه‌چیز (توکن، پیش‌نویس‌ها، تنظیمات) فقط روی دستگاه خودت می‌ماند.

```bash
python insta_agent.py --demo     # اول این را بزن: یک پیج ساختگی، بدون توکن و بدون اینترنت
python insta_agent.py            # اجرای واقعی
```

## چه کارهایی می‌کند؟

| بخش | کار |
| --- | --- |
| **انتشار** | پست تکی، پست چندتایی (۲ تا ۲۰ تایی)، ریل و استوری — همین حالا یا در زمان دلخواه. کپشن، متن جایگزین عکس، «اولین کامنت»، بستن کامنت‌ها، نمایش ریل در صفحهٔ اصلی. |
| **زمان‌بندی** | صف انتشار، پیش‌نویس‌ها، پیشنهاد «بهترین ساعت» از روی پست‌های قبلی خودت. اگر اینترنت قطع شود خودش دوباره تلاش می‌کند و **هیچ پستی را دو بار منتشر نمی‌کند**. |
| **کامنت‌ها** | همهٔ کامنت‌های بی‌پاسخ در یک صندوق: پاسخ، پیام خصوصی به نویسندهٔ کامنت، مخفی‌کردن، حذف، «رسیدگی شد». |
| **دایرکت** | دیدن گفتگوها و جواب دادن (در پنجرهٔ ۲۴ ساعتهٔ اینستاگرام). |
| **پاسخ خودکار** | قانون با کلمهٔ کلیدی (مثلاً «قیمت» ← متن آماده + پیام خصوصی)، چند متن تصادفی، `{username}`، مخفی‌کردن خودکار کامنت‌های تبلیغاتی. |
| **آمار** | ریچ، بازدید، تعامل، رشد دنبال‌کننده، بهترین پست‌ها، بهترین ساعت‌ها، سن و جنسیت و شهر مخاطبان، آمار هر پست. |
| **دستیار** | کپشن و هشتگ پیشنهادی، ایدهٔ پست، چیدن برنامهٔ محتوایی به شکل پیش‌نویس، پیشنهاد پاسخ برای کامنت و دایرکت. |
| **خبر دادن** | هشدار و گزارش شبانه در تلگرام (اختیاری). |

همهٔ کارهای خودکار **در شروع خاموش‌اند**؛ هر کدام را خودت در بخش «ایجنت» روشن می‌کنی.

## شروع سریع

### روی گوشی اندروید (Termux)

```bash
pkg update && pkg install -y python git cloudflared
git clone https://github.com/afshinrahimi109/Najibrahimi
cd Najibrahimi/insta-agent
termux-wake-lock                 # تا گوشی برنامه را نخواباند
python insta_agent.py
```

برنامه یک نشانی مثل `http://127.0.0.1:8787/?k=ABCDE-FGHJK` چاپ می‌کند و مرورگر را باز می‌کند.
اگر باز نشد همان نشانی را در کروم گوشی بزن. از منوی کروم «Add to Home screen» را بزنی، پنل مثل یک اپ روی صفحهٔ گوشی می‌نشیند.

### روی کامپیوتر (ویندوز، لینوکس، مک)

```bash
git clone https://github.com/afshinrahimi109/Najibrahimi
cd Najibrahimi/insta-agent
python insta_agent.py
```

برنامه فقط همین یک فایل `insta_agent.py` است؛ اگر بخواهی می‌توانی فقط همان را برداری و اجرا کنی.

### گزینه‌های اجرا

| دستور | کار |
| --- | --- |
| `python insta_agent.py --demo` | حالت نمایشی با پیج ساختگی `@demo.cafe` (هیچ چیزی به اینستاگرام واقعی نمی‌رود) |
| `python insta_agent.py --show-key` | نمایش دوبارهٔ کد ورود پنل |
| `python insta_agent.py --port 9000` | پورت دیگر |
| `python insta_agent.py --host 0.0.0.0` | باز شدن پنل از دستگاه‌های دیگرِ همان وای‌فای (کد ورود لازم است) |
| `python insta_agent.py --no-browser` | مرورگر را خودکار باز نکن |
| `python insta_agent.py --data پوشه` | جای نگهداری داده‌ها (پیش‌فرض `~/.insta_agent`) |

## وصل‌کردن پیج (فقط یک بار، حدود ۵ دقیقه)

ایجنت با یک **توکن** به پیج وصل می‌شود. توکن را خود Meta به تو می‌دهد و هر وقت بخواهی می‌توانی باطلش کنی.

1. پیج باید **حرفه‌ای** (Business یا Creator) باشد: اینستاگرام ← تنظیمات ← نوع حساب ← «تغییر به حساب حرفه‌ای». رایگان است.
2. در <https://developers.facebook.com/apps/> وارد شو و **Create App** را بزن.
   اگر «Use case» پرسید، گزینهٔ مربوط به اینستاگرام (*Manage messaging & content on Instagram*) را بردار؛ در فرم قدیمی‌تر: *Other* ← *Business*.
3. در برنامه‌ای که ساختی محصول **Instagram** را اضافه کن و به بخش **API setup with Instagram login** برو.
4. در قسمت **Generate access tokens** پیج خودت را اضافه کن (Add account)، با همان پیج وارد شو، همهٔ دسترسی‌ها را تأیید کن و **Generate token** را بزن.
5. رشتهٔ بلندی که با `IGAA` شروع می‌شود را کپی کن و در پنل بچسبان.

- توکن ۶۰ روز اعتبار دارد؛ ایجنت هر هفته خودش تمدیدش می‌کند. اگر برنامه بیش از ۶۰ روز خاموش بماند باید توکن تازه بسازی.
- توکن‌های قدیمی‌تر «Facebook Login» (که با `EAA` شروع می‌شوند) هم پذیرفته می‌شوند؛ ایجنت خودش صفحهٔ فیسبوکِ وصل به پیج را پیدا می‌کند.
- نام منوها در سایت Meta گاهی عوض می‌شود؛ مقصد همیشه همان بخش «Generate access tokens» زیر محصول Instagram است.
- اینستاگرام بدون فیلترشکن باز نمی‌شود؟ در صفحهٔ اتصال (یا تنظیمات ← پروکسی) نشانی پروکسی **HTTP** فیلترشکن را بده؛ در v2rayNG معمولاً `http://127.0.0.1:10809`.

## انتشار از گالری و «لینک عمومی»

اینستاگرام فایل را از تو نمی‌گیرد؛ خودش آن را از یک **نشانی اینترنتی** برمی‌دارد. پس وقتی عکسی را از گالری انتخاب می‌کنی،
ایجنت باید چند دقیقه یک لینک عمومی برای همان فایل بسازد. سه راه دارد (تنظیمات ← انتشار از گالری):

1. **تونل `cloudflared` (پیشنهادی، رایگان، بدون ثبت‌نام):** کافی است نصب باشد (`pkg install cloudflared`). ایجنت فقط وقتی لازم است تونل را باز می‌کند و فقط همان فایل‌های در حال انتشار از آن دیده می‌شوند، نه پنل.
2. **میزبان موقت:** فایل برای یک ساعت روی سرویس عمومی `litterbox.catbox.moe` گذاشته می‌شود. چیزی نصب نمی‌خواهد ولی فایل از دستگاهت بیرون می‌رود؛ برای همین باید خودت روشنش کنی.
3. **نشانی عمومی خودت:** اگر ایجنت روی سرور یا پشت دامنهٔ خودت است.

اگر به‌جای فایل، **لینک مستقیم** عکس یا ویدیو (`https://…`) بدهی، هیچ‌کدام لازم نیست.

عکس‌ها در مرورگر خودکار به JPEG تبدیل و اگر لازم باشد به نسبت مجاز اینستاگرام (۴:۵ تا ۱٫۹۱:۱) بریده می‌شوند.
ویدیو باید MP4 یا MOV باشد (بهتر است H.264 و عمودی ۹:۱۶)؛ ایجنت ویدیو را تبدیل نمی‌کند.

## پاسخ خودکار و ترمزهای ایمنی

در بخش «ایجنت» قانون می‌سازی: «اگر کامنت شامل *قیمت* یا *چنده* بود ← این متن را زیرش بنویس و این پیام را خصوصی بفرست».
حروف «ي/ی» و «ك/ک»، نیم‌فاصله و بزرگی و کوچکی حروف فرقی نمی‌کند.

برای این‌که پیج شبیه ربات نشود و اینستاگرام حساس نشود، ایجنت این ترمزها را دارد:

- فقط به چیزهایی جواب می‌دهد که **بعد از روشن‌کردن کلید** رسیده‌اند و کمتر از ۲۴ ساعت از آن‌ها گذشته است؛ کامنت‌های قدیمی را یک‌جا جواب نمی‌دهد.
- به هر کامنت یا پیام **حداکثر یک بار** جواب می‌دهد، حتی اگر وسط کار اینترنت قطع شود.
- به هر نفر هر ۳۰ دقیقه یک پاسخ خودکار (قابل تغییر).
- سقف ۳۰ کار خودکار در ساعت (قابل تغییر).
- «ساعت سکوت»: در این بازه (مثلاً ۲۳ تا ۸) چیزی فرستاده نمی‌شود و صبح جواب داده می‌شود.
- کلید «ایجنت روشن/خاموش» در خانه همه‌چیز را یک‌جا نگه می‌دارد.
- پاسخ‌های هوش مصنوعی به‌طور پیش‌فرض فقط **پیشنهاد** هستند و در کادر پاسخ می‌نشینند؛ فرستادن خودکارشان کلید جدا دارد.

## تنظیم با فایل `.env` (اختیاری)

همه‌چیز از داخل پنل تنظیم می‌شود. اگر بخواهی، می‌توانی فایل [`.env.example`](.env.example) را به نام `.env` کنار برنامه کپی کنی:

| متغیر | کار |
| --- | --- |
| `AGENT_PORT` / `AGENT_HOST` | پورت و نشانی پنل (پیش‌فرض `8787` و `127.0.0.1`) |
| `AGENT_PASSWORD` | کد ورود دلخواه به‌جای کد خودکار |
| `AGENT_DATA_DIR` | پوشهٔ داده‌ها |
| `AGENT_PROXY` | پروکسی HTTP برای رسیدن به اینستاگرام |
| `AGENT_PUBLIC_URL` | نشانی عمومی خودت برای فایل‌ها |
| `AGENT_TUNNEL_CMD` | دستور تونل دلخواه؛ `{port}` با پورت فایل‌ها جایگزین می‌شود |
| `IG_ACCESS_TOKEN` | توکن (به‌جای چسباندن در پنل) |
| `IG_API_VERSION` | نسخهٔ API (پیش‌فرض `v27.0`؛ اگر پذیرفته نشود خودش نسخهٔ قبلی را امتحان می‌کند) |
| `AGENT_AI_URL` | نشانی یک سرویس سازگار با OpenAI برای دستیار |

## همیشه روشن (Termux)

زمان‌بندی و پاسخ خودکار فقط تا وقتی کار می‌کند که برنامه باز باشد.

- `termux-wake-lock` را بزن و در تنظیمات اندروید «بهینه‌سازی باتری» را برای Termux خاموش کن.
- برای شروع خودکار بعد از روشن شدن گوشی، اپ **Termux:Boot** را نصب کن و:

```bash
mkdir -p ~/.termux/boot
cp termux-boot.sh ~/.termux/boot/insta-agent.sh
```

اگر برنامه خاموش بوده، پست‌هایی که کمتر از ۶ ساعت از وقتشان گذشته همان موقعِ روشن شدن منتشر می‌شوند؛ قدیمی‌ترها «جامانده» علامت می‌خورند تا خودت تصمیم بگیری.

## امنیت

- پنل فقط روی خود دستگاه باز می‌شود مگر این‌که خودت `--host 0.0.0.0` بدهی.
- ورود با کدی است که هنگام اجرا در ترمینال چاپ می‌شود؛ بعد از ۸ بار اشتباه، ورود ۱۰ دقیقه بسته می‌شود.
- توکن هیچ‌وقت به مرورگر برنمی‌گردد و در گزارش‌ها هم نوشته نمی‌شود. با «قطع اتصال» از روی دستگاه پاک می‌شود.
- تونل `cloudflared` فقط فایل‌های در حال انتشار را نشان می‌دهد؛ پنل و داده‌ها پشت آن نیستند.
- پوشهٔ داده‌ها (`~/.insta_agent`) را با کسی شریک نشو؛ توکن پیج داخل آن است.

## چه چیزهایی شدنی نیست؟ (روراست)

Meta برای این کارها **راه رسمی نگذاشته** و این ایجنت هم سراغ راه‌های غیررسمی (که پیج را در خطر بسته‌شدن می‌گذارند) نمی‌رود:

- فالو/آنفالو، لایک‌کردن، دیدن فهرست دنبال‌کننده‌ها، دیدن استوری دیگران
- ویرایش کپشن یا بیو
- استیکر، لینک، موسیقی و نظرسنجی روی استوری؛ موسیقی کتابخانهٔ اینستاگرام روی ریل
- شروع گفتگو با کسی که خودش پیام نداده، یا جواب بعد از ۲۴ ساعت

دو نکتهٔ دیگر:

- **دایرکت با عموم مردم** فقط وقتی کار می‌کند که برنامه‌ات در Meta «Advanced Access» گرفته باشد (App Review). تا آن موقع فقط با حساب‌هایی که در برنامه نقش دارند کار می‌کند. کامنت‌ها، انتشار و آمار این محدودیت را ندارند.
- اینستاگرام برای انتشار از راه API سقف ۲۴ ساعته دارد؛ ایجنت عدد واقعی را از خود اینستاگرام می‌پرسد و در خانه نشان می‌دهد. سقف خودِ ایجنت ۲۵ پست در روز است که قابل تغییر است.
- ایجنت هیچ پستی را از پیج **حذف نمی‌کند**؛ این کار را از خود اپ اینستاگرام انجام بده.

## رفع اشکال

| مشکل | راه |
| --- | --- |
| «اینستاگرام این توکن را نپذیرفت» | توکن ناقص کپی شده یا باطل است؛ یک توکن تازه بساز. |
| «ارتباط با اینستاگرام برقرار نشد» | اینترنت یا فیلترشکن؛ پروکسی HTTP را در تنظیمات بده. |
| انتشار از گالری جلو نمی‌رود | `cloudflared` نصب نیست یا تونل بالا نیامده؛ در تنظیمات «میزبان موقت» را روشن کن یا لینک مستقیم بده. |
| «اینستاگرام نتوانست فایل را بردارد» | ویدیو با فرمت نامناسب (H.264/AAC در MP4 بهتر است) یا لینک عمومی در دسترس نبوده؛ دوباره تلاش کن. |
| دایرکت‌ها خالی است | برنامه‌ات هنوز Advanced Access ندارد (بالا را ببین). |
| کد ورود را گم کرده‌ام | `python insta_agent.py --show-key` |
| «ایجنت همین حالا در حال اجراست» | یک نسخهٔ دیگر باز است؛ اول آن را ببند. |

## برای توسعه‌دهنده‌ها

داخل همین فایل یک **شبیه‌ساز API اینستاگرام** هست؛ حالت نمایشی و همهٔ تست‌ها با آن کار می‌کنند و اینترنت نمی‌خواهند.

```bash
cd tests
python -m unittest discover -p "test_*.py"     # حدود ۲۰۰ تست: انتشار، صندوق، خودکارها، توکن، آمار، امنیت پنل

cd ui                                          # پنل در مرورگر واقعی (Node لازم است)
sh setup.sh
python serve.py flows.mjs demo                 # کارهای روزمره: انتشار، زمان‌بندی، پاسخ، قانون، تنظیمات…
python serve.py connect.mjs sim                # ورود با کد، اتصال پیج، قطع اتصال
```

این تست‌ها روی هر تغییر در GitHub Actions هم اجرا می‌شوند (لینوکس با پایتون ۳٫۸ تا ۳٫۱۳، ویندوز، و کروم واقعی).

یادآوری: این تست‌ها رفتار برنامه را در برابر شبیه‌ساز می‌سنجند. شبیه‌ساز از روی مستندات رسمی Meta نوشته شده،
ولی جای اینستاگرام واقعی را نمی‌گیرد؛ اولین پست واقعی را خودت با یک عکس آزمایشی امتحان کن.
