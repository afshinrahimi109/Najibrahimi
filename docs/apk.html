🔐 دانلود FreeVPN.apk

اگه لینک Release گیتھاب تو شبکهٔ تو پیغام «بارگیری به تعلیق افتاد / Download paused» میده، دلیلش CDN است: فایلهای Release از روی release-assets.githubusercontent.com میان که تو خیلی از شبکهها مسدود یا کند است. APK الان داخل خود مخزن هم هست، پس چند تا دامنهٔ کاملاً متفاوت داری — به ترتیب امتحان کن:

✅ نسخهٔ فعلی: ۲۶٬۳۸۹ بایت — sha256: c77e45210f8932848e919dc78dccab4c9473dffd283f250bf8a00c8e29f982fe

🥇 روش صفر: اگه Termux داری، اصلاً دانلود نکن!

چون APK داخل خود گیتھابه، فقط ریپازیتوری رو آپدیت کن و مستقیم نصبش کن (این مطمئنترین راه تو ایران است، چون از همون کانالی میاد که git clone ات کار میکند):

cd ~/Najibrahimi
git pull origin arena/621700c4-najibrahimi
sha256sum docs/FreeVPN.apk
termux-open docs/FreeVPN.apk

اگه ریپو رو نداری: git clone -b arena/621700c4-najibrahimi --depth 1 https://github.com/afshinrahimi109/Najibrahimi.git ~/Najibrahimi

🥈 لینکهای جایگزین (روی گوشی کلیک کن)

⬇️ ۱) ZIP کل مخزن از codeload.github.com (فقط ۳۶۴ کیلوبایت — تستشده ✅) ⬇️ ۲) jsDelivr CDN ⬇️ ۳) github.com/raw ⬇️ ۴) raw.githubusercontent.com ⬇️ ۵) GitHub Pages (همین سایت) ⬇️ ۶) پروکسی gh-proxy.com ⬇️ ۷) پروکسی ghproxy.net ⬇️ ۸) لینک اصلی Release

روش ۱: فایل ZIP رو باز کن → برو تو پوشهٔ Najibrahimi-arena-621700c4-najibrahimi/docs/ → FreeVPN.apk رو بزن تا نصب شود.

⚠️ نکتهها: پروکسیها سرویس شخص ثالث و موقتیاند — حتماً بعدش sha256sum FreeVPN.apk رو با امضای بالا چک کن. دکمهٔ ۵ (Pages) هم فقط وقتی کار میکند که Pages تو تنظیمات مخزن فعال باشد (Settings → Pages → Deploy from a branch → arena/621700c4-najibrahimi / docs)؛ workflow سعی کرد خودکار فعالش کند ولی گیتھاب اجازه نداد (HTTP 403)، باید دستی بزنی.

🥉 راه تضمینی: فقط یه فایل متنی (بدون دانلود باینری)

بعضی شبکهها فقط فایلهای .apk رو قطع میکنن. یه نسخهٔ متنیِ base64 هم گذاشتیم؛ تو Termux بزن:

curl -fsSL -o f.b64 https://cdn.jsdelivr.net/gh/afshinrahimi109/Najibrahimi@arena%2F621700c4-najibrahimi/docs/FreeVPN.apk.base64.txt
base64 -d f.b64 > FreeVPN.apk && sha256sum FreeVPN.apk && termux-open FreeVPN.apk

یا اسکریپت آماده (همهٔ لینکها رو خودش امتحان میکند و sha256 رو چک میکند):

curl -fsSL -o i.sh https://raw.githubusercontent.com/afshinrahimi109/Najibrahimi/arena/621700c4-najibrahimi/docs/install-apk.sh && bash i.sh

اگه نصب نشد: termux-setup-storage رو بزن، فایل رو به ~/storage/downloads/ کپی کن و از فایلمنیجر بازش کن.

🛠 نکات ساده ولی مؤثر

  • دانلودمنیجر «معلق» میشه چون وسط کار ارتباط قطع میشه. یه دانلودمنیجر با Resume نصب کن (1DM / ADM) یا تو ترموکس curl -C - بزن.
  • یه بار وایفای ↔ دیتای موبایل رو عوض کن؛ بعضی ISPها فقط یه مسیرشون بلاکه.
  • مرورگر دیگه (Chrome → Firefox) یا حالت ناشناس رو امتحان کن.
  • اگه VPN/پروکسی دیگهای روشنه، موقع دانلود خاموشش کن.
