🔐 دانلود FreeVPN.apk

اگه لینک Release گیتھاب تو شبکهٔ تو پیغام «بارگیری به تعلیق افتاد / Download paused» میده، دلیلش CDN هاست: فایلهای Release از روی release-assets.githubusercontent.com میان که تو خیلی از شبکهها مسدود یا کند است. این صفحه چند مسیر جایگزین دارد — به ترتیب امتحان کن:

۱) لینکهای جایگزین (روی گوشی کلیک کن)

⬇️ ۱) github.com/raw — پیشنهاد اول ⬇️ ۲) GitHub Pages (همین سایت) ⬇️ ۳) raw.githubusercontent.com ⬇️ پروکسی gh-proxy.com ⬇️ پروکسی ghproxy.net ⬇️ لینک اصلی Release (اگه کار کرد)

⚠️ دکمهٔ ۲ (GitHub Pages) فقط وقتی کار میکند که Pages تو تنظیمات مخزن فعال باشد (Settings → Pages → Deploy from a branch → arena/621700c4-najibrahimi / docs). workflow سعی میکند خودکار فعالش کند. پروکسیها هم سرویس شخص ثالث هستند؛ حتماً بعد از دانلود امضای فایل رو با FreeVPN.apk.sha256 چک کن (sha256sum FreeVPN.apk). حجم فایل حدود ۲۶ کیلوبایت است.

۲) راه تضمینی: فقط یه فایل متنی (بدون دانلود باینری)

بعضی شبکهها فقط فایلهای .apk رو قطع میکنن. ما یه نسخهٔ متنیِ base64 هم گذاشتیم؛ تو Termux این سه خط رو بزن:

pkg install curl coreutils -y
curl -fsSL -o f.b64 https://raw.githubusercontent.com/afshinrahimi109/Najibrahimi/arena/621700c4-najibrahimi/docs/FreeVPN.apk.base64.txt
base64 -d f.b64 > FreeVPN.apk && sha256sum FreeVPN.apk && termux-open FreeVPN.apk

یا اسکریپت آماده:

curl -fsSL -o i.sh https://raw.githubusercontent.com/afshinrahimi109/Najibrahimi/arena/621700c4-najibrahimi/docs/install-apk.sh && bash i.sh

اگه نصب نشد: termux-setup-storage رو بزن و فایل رو به ~/storage/downloads/ کپی کن و از فایلمنیجر بازش کن.

۳) نکات ساده ولی مؤثر

  • دانلودمنیجر اندروید «معلق» میشه چون وسط کار ارتباط قطع میشه. یه دانلودمنیجر با قابلیت Resume نصب کن (مثلاً 1DM / ADM) یا تو ترموکس از curl -C - استفاده کن.
  • یه بار وایفای ↔ دیتای موبایل رو عوض کن؛ بعضی ISPها فقط یه مسیرشون بلاکه.
  • مرورگر دیگه (Chrome → Firefox) یا حالت ناشناس رو امتحان کن.
  • اگه VPN/پروکسی دیگهای روشنه، موقع دانلود خاموشش کن تا مستقیم وصل بشی.

بعد از نصب، لینک vless:// سرورت رو تو اپ پیست کن و دکمهٔ «🔍 تست اتصال» رو بزن تا بفهمی دقیقاً کجای کار گیر کرده. راهنما: vpn/android/README.md
