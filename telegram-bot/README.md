# Holo Agent — بات خصوصی تلگرام فارسی

## ساده‌ترین راه روی گوشی اندروید (Termux)

این روش روی خود گوشی اجرا می‌شود و به ساخت سرور یا حساب هاست نیاز ندارد. گوشی باید اینترنت داشته باشد و Termux باز بماند؛ اگر EMUI برنامه را ببندد، بات موقتاً آفلاین می‌شود.

1. Termux را از **F-Droid** نصب کن (نسخهٔ Google Play را نصب نکن).
2. Termux را باز کن و این دو خط را جداگانه اجرا کن:

   ```bash
   pkg update -y && pkg install python git -y
   git clone -b arena/07a5df28-najibrahimi https://github.com/afshinrahimi109/Najibrahimi.git
   cd Najibrahimi/telegram-bot
   bash setup.sh
   ```

3. راه‌انداز توکن BotFather و شناسهٔ عددی تلگرامت را می‌گیرد، بعد می‌توانی Gemini، Groq یا مدل عمومیِ بدون کلید را انتخاب کنی. گزینهٔ ۳ نیازی به API key ندارد. اگر کلید وارد می‌کنی، هنگام تایپ مخفی می‌ماند؛ **در چت برای کسی نفرست**.
4. وقتی پیام «ربات در حال اجراست» را دیدی، تلگرام را باز کن، رباتت را پیدا کن و `/start` بفرست. برای خاموش‌کردن بات، به Termux برگرد و `Ctrl+C` بزن.

برای فعال‌ماندن بیشتر روی گوشی Huawei، در تنظیمات باتری/برنامه‌ها، محدودیت اجرای پس‌زمینه و بهینه‌سازی باتری Termux را غیرفعال کن. حالت اطمینان‌پذیرتر، اجرای همین کد روی یک هاست همیشه‌روشن است؛ اما برای شروع لازم نیست.

اگر کلیدهای Gemini/Groq در دسترس نیستند، در راه‌انداز گزینهٔ ۳ را انتخاب کن؛ پاسخ متنی از Pollinations می‌آید و API key نمی‌خواهد. برای ویس، کلید معتبر Gemini یا Groq لازم است. برای ساخت کلید: [Google AI Studio](https://aistudio.google.com/apikey) یا [Groq Console](https://console.groq.com/keys).


Holo Agent برای استفادهٔ شخصی از تلگرام طراحی شده است: پیام متنی و ویس می‌گیرد، با مدل زبانی گفتگو و متن را خلاصه می‌کند، وب را جستجو می‌کند، تصویر می‌سازد، یادداشت‌ها و کارها را نگه می‌دارد، یادآوری‌های ماندگار و قابل لغو می‌فرستد، برای ریل و کانال پیش‌نویس می‌سازد و فقط با دستور صریح `/publish` در کانال منتشر می‌کند.

> **سرویس عمومی و حریم خصوصی:** اگر هیچ کلید هوش مصنوعی کار نکند، بات برای پاسخ متنی به مدل عمومی Pollinations متصل می‌شود؛ این سرویس ChatGPT یا Claude نیست و ممکن است ناپایدار باشد. پیام‌ها و متن گفتگو برای ساخت پاسخ به سرویس بیرونی فرستاده می‌شوند؛ اطلاعات حساس نفرست. Gemini یا Groq معتبر برای تبدیل ویس لازم است. سهمیه و رایگان‌بودن سرویس‌ها ممکن است تغییر کند؛ جستجو و تصویر نیز سرویس‌های ثالث‌اند.

## امنیت و رفتار

- بات فقط به شناسهٔ عددی `TELEGRAM_OWNER_ID` و فقط در گفت‌وگوی خصوصی پاسخ می‌دهد.
- توکن بات و API keyها را فقط در `.env` محلیِ نادیده‌گرفته‌شده یا Variables هاست وارد کن؛ آن‌ها را در مخزن یا چت نگذار.
- برای انتشار کانال، خودت بات را مدیر کانال کن و `TELEGRAM_CHANNEL_ID` را تنظیم کن. هیچ محتوایی خودکار منتشر نمی‌شود؛ انتشار فقط با `/publish <شناسه>` انجام می‌شود.
- ویس برای تبدیل به ارائه‌دهندهٔ فعال (Gemini یا Groq) فرستاده می‌شود. فایل صوتی در دیسک محلی ذخیره نمی‌شود.
- یادآوری‌ها، یادداشت‌ها، کارها و پیش‌نویس‌ها در SQLite هستند. یک Volume پایدار برای مسیر `/app/data` در هاست متصل کن.
- اگر کلید Groq یا Gemini رد شد، نسخهٔ جدید چت متنی را خودکار به مدل عمومیِ بدون کلید می‌سپارد. در Termux بات را با `Ctrl+C` متوقف کن، از پوشهٔ مخزن `git pull` بزن و `bash setup.sh` را اجرا کن. تنظیمات فعلی و یادداشت‌ها حفظ می‌شوند؛ تبدیل ویس همچنان به کلید معتبر نیاز دارد.

## قابلیت‌ها و فرمان‌ها

- `/start` و `/help` — راهنما
- متن آزاد — گفتگو با Holo (حافظهٔ کوتاه‌مدت مکالمه در همان نشست)
- ویس تلگرام — تبدیل گفتار فارسی با Gemini یا Groq و سپس اجرای همان درخواست
- `/search <عبارت>` — جستجوی وب DuckDuckGo و خلاصهٔ نتایج به‌کمک مدل
- `/summarize <متن>` — خلاصه‌سازی متن؛ با پیام «خلاصه کن: ...» هم کار می‌کند
- `/image <توضیح>` — ساخت تصویر با Pollinations
- `/note <متن>` و `/notes` و `/notedel <شناسه>` — یادداشت خصوصی و ماندگار
- `/todo add <کار>`، `/todo list`، `/todo done <شناسه>`، `/todo delete <شناسه>` — مدیریت فهرست کارها
- `/reel <موضوع>` — تولید پیش‌نویس فارسی برای ریل
- `/post <موضوع>` — تولید پست کانال تلگرام و ذخیره به‌عنوان پیش‌نویس
- `/drafts` و `/draft <شناسه>` — فهرست و نمایش پیش‌نویس‌ها
- `/publish <شناسه>` — انتشار صریح یک پیش‌نویس ذخیره‌شده در کانال (فقط اگر کانال تنظیم و بات مدیر باشد)
- `/remind <زمان> <متن>` — یادآوری ماندگار؛ نمونه‌ها: `/remind 30m تماس با دوست`، `/remind 2h جلسه`، `/remind ۳۰ دقیقه تماس با دوست`
- `/reminders` و `/cancelreminder <شناسه>` — دیدن یا لغو یادآوری‌های درانتظار
- `/status` — وضعیت سرویس‌ها، تعداد یادداشت‌ها، کارهای باز و پیش‌نویس‌ها

درخواست‌های متنی مثل «جستجو کن ...»، «یه عکس از ... بساز» یا «یه پست درباره ... بنویس» هم به ابزار مرتبط هدایت می‌شوند.

## اجرای محلی (Linux / macOS / Termux)

پیش‌نیاز: Python 3.10 یا جدیدتر.

```bash
cd telegram-bot
cp .env.example .env
# در .env مقدار TELEGRAM_BOT_TOKEN و TELEGRAM_OWNER_ID را وارد کن؛ GEMINI_API_KEY یا GROQ_API_KEY را تنظیم کن.
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

در اندروید، Termux جدید را از F-Droid یا منبع رسمی نصب کن؛ اما برای کار پیوسته و پایدار، سرور آنلاین مناسب‌تر است. بات با long polling کار می‌کند و به بازکردن پورت ورودی نیازی ندارد.

## Docker Compose

```bash
cd telegram-bot
cp .env.example .env
# .env را تکمیل کن

docker compose up --build -d
docker compose logs -f telegram-bot
```

SQLite در volume به‌نام `drafts` نگه‌داری می‌شود. برای توقف `docker compose down` را اجرا کن؛ volume را فقط اگر می‌خواهی داده‌ها پاک شوند حذف کن.

## استقرار روی یک میزبان ابری

سرویس Docker را از همین مخزن بساز و Root Directory را روی `telegram-bot` قرار بده. Volume دائمی را روی `/app/data` متصل کن و متغیرهای زیر را در پنل هاست بگذار:

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ساخته‌شده با BotFather |
| `TELEGRAM_OWNER_ID` | شناسهٔ عددی مالک تلگرام |
| `GEMINI_API_KEY` | اختیاری؛ Gemini برای مدل زبانی و ویس (اگر تنظیم باشد بر Groq اولویت دارد) |
| `GEMINI_MODEL` | پیش‌فرض `gemini-2.5-flash` |
| `GROQ_API_KEY` | اختیاری؛ کلید Groq برای مدل زبانی و ویس |
| `GROQ_MODEL` | پیش‌فرض `llama-3.3-70b-versatile` |
| `TELEGRAM_CHANNEL_ID` | اختیاری؛ شناسه یا نام کانال، با دسترسی مدیر برای بات |
| `DATABASE_PATH` | اختیاری؛ در Docker پیش‌فرض `/app/data/drafts.sqlite3` است |
| `OPENROUTER_API_KEY` | اختیاری؛ جایگزین LLM چت/محتوا، بدون تبدیل ویس |
| `OPENROUTER_MODEL` | مدل جایگزین، پیش‌فرض `openai/gpt-4o-mini` |

برای استفادهٔ شخصی، `TELEGRAM_OWNER_ID` را حتماً تنظیم کن. فقط private بودن مخزن امنیت توکن را تضمین نمی‌کند؛ از `.env` در Git استفاده نکن. اگر توکنی قبلاً افشا شده، آن را در BotFather باطل کن.
