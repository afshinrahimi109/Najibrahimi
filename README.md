# کی‌کرفت (K-Craft) | شبیه‌ساز ماین‌کرفت با شخصیت‌های کره‌ای 🇰🇷⛏️

یک بازی سه‌بعدی شبیه‌سازی‌شده از **ماین‌کرفت (Minecraft)** با موتور وکسل اختصاصی **Three.js + React + TypeScript** که در آن **تمامی شخصیت‌ها (بازیکن، اهالی دهکده، نگهبانان چوسان، آیدل‌ها و حتی مهاجمان افسانه‌ای شب)** دارای چهره، مدل مو و پوشش اصیل کره‌ای هستند.

## ✨ ویژگی‌های کلیدی

- **شخصیت‌هایی با چهره کاملاً کره‌ای:**
  - طراحی چهره با جزئیات بالا (پوست روشن و طبیعی کره‌ای، چشم‌های تک‌پلک `무쌍`، دوپلک ظریف `속쌍`، چشم خندان `눈웃음`، ابروهای صاف کره‌ای `일자 눈썹`، تینت لب گرادیانی `그라데이션 립` و خط لبخند زیر چشم `애교살`).
  - مدل مو و کلاه‌های سه‌بعدی کره‌ای: مدل دوطبقه کاما (`투블럭 가르마`)، چتری سی‌ترو با روبان قرمز دنگی (`댕기`)، کلاه سنتی گات چوسان (`갓`)، شینیون سنتی با سنجاق سر یشم (`비녀`)، کلاه حصیری سات‌گات (`삿갓`) و فر کلاسیک مادربزرگ کره‌ای (`할머니 파마`).
  - استودیو شخصی‌سازی زنده چهره و پوشش در هر لحظه از بازی (کلید `C`).
- **موتور وکسل سه‌بعدی ماین‌کرفت (۶۰ فریم بر ثانیه):**
  - جهان چانک‌بندی‌شده با سایه‌زنی محیطی (Vertex Ambient Occlusion)، غار معدنی، کوهستان سنگ‌های قیمتی (زغال، آهن، طلا، الماس)، برکه آب، پل چوبی و باغ شکوفه‌های گیلاس (`벚꽃`).
  - معماری اصیل کره‌ای با بلوک‌های قابل استخراج و ساخت‌وساز: سفال سقف هانوک (`기와`)، پنجره کاغذی هانجی (`한지창`)، ستون قرمز معبد (`단청 기둥`) و فانوس ابریشمی (`청사초롱`).
- **گیم‌پلی کامل بقا و خلاقیت:**
  - استخراج بلوک‌ها، ساخت‌وساز (Crafting)، انفجار بلوک‌های `TNT`، خوردن کیمباب (`김밥`) و توکبوکی (`떡볶이`)، چرخه پویا روز و شب، گفتگو و معامله با اهالی کره‌ای و دعوت از آن‌ها به عنوان **یار همراه**!
  - ۳ حالت دوربین (کلید `V`): **اول‌شخص**، **سوم‌شخص از پشت** و **نمای سلفی روبه‌رو چهره کره‌ای**.

## 🎮 کلیدهای کنترل

| کلید / عمل | کاربرد |
| --- | --- |
| `W` `A` `S` `D` + `Space` | حرکت در چهار جهت و پرش / شنا |
| `Shift` | دویدن سریع |
| `کلیک چپ` | شکستن بلوک / روشن کردن TNT / ضربه شمشیر |
| `کلیک راست` (یا کلید `R`) | گذاشتن بلوک / خوردن کیمباب و توکبوکی |
| `1` تا `9` یا اسکرول | انتخاب اسلات نوار ابزار |
| `V` | تغییر دوربین (اول‌شخص / سوم‌شخص / سلفی چهره کره‌ای) |
| `C` | باز کردن استودیو طراحی چهره و لباس کره‌ای |
| `E` | کیف ابزار، ساخت‌وساز و کاتالوگ تمام بلوک‌ها |
| `F` | گفتگو، معامله و همراه کردن اهالی کره‌ای دهکده |
| `G` | تغییر حالت بقا (Survival) و خلاقیت بی‌نهایت (Creative) |
| `N` | تغییر سریع روز بهاری و شب فانوس‌های ابریشمی |

## 📲 نصب روی گوشی اندروید و کامپیوتر (فایل نصبی آماده)

1. **فایل نصبی اندروید (`K-Craft-Korea.apk`):**
   - فایل رسمی و امضاشده (APK Signature v1/v2/v3) با حجم فقط **۴۰۵ کیلوبایت** و کارکرد **۱۰۰٪ آفلاین** در ریشه مخزن قرار دارد.
   - کافی است فایل **`K-Craft-Korea.apk`** را دانلود کرده و روی گوشی اندروید نصب کنید (آیکون اختصاصی «کی‌کرفت» به صفحه اصلی اضافه می‌شود).
2. **نسخه تک‌فایل بدون نیاز به نصب (`k-craft-korea.html`):**
   - قابل باز شدن مستقیم در هر مرورگر موبایل یا ویندوز/مک با یک کلیک.
3. **نصب به صورت وب‌اپلیکیشن (PWA):**
   - پشتیبانی از نصب تمام‌صفحه روی اندروید، آیفون و ویندوز با Service Worker آفلاین.

## 🔐 VPN رایگان با آدرس ثابت (ساختهشده از صفر)

اگه دنبال یه VPN رایگان و بدون کارت بانکی هستی که همیشه بهش وصل شی،
پوشهٔ [`vpn/`](vpn/README.md) رو ببین: یه رله VLESS/WebSocket کاملاً نوشتهشده با
کتابخانه استاندارد پایتون، همراه کلاینت SOCKS5 مخصوص ترموکس، دیپلوی یککلیک روی
پلن رایگان Render (آدرس ثابت `*.onrender.com`)، و تستهای انتها به انتها.

```bash
cd vpn && python3 tests/test_relay.py
```

همچنین یه اپ اندرویدی VPN اختصاصی (`VpnService` + تونل VLESS، بدون کتابخانه خارجی)
تو [`vpn/android/`](vpn/android/README.md) هست که GitHub Actions برات APK میسازد و
مستقیم تو [Releases](https://github.com/afshinrahimi109/Najibrahimi/releases/tag/v1.0.0) میگذارد: [دانلود FreeVPN.apk](https://github.com/afshinrahimi109/Najibrahimi/releases/download/v1.0.0/FreeVPN.apk).
